## Question and Single Intended Change

Can other approved inner-fit sources, under the SAME producer/controller
context, repair reference coverage without destroying conditional information?
Pool the four registered fitting packets for that context. Never pool different
contexts, inner-held recordings, outer development or reserved roles.

The same380 causal feature columns are retained. History, neighbors and rollout
coordinates use observed-scale normalization; column354 retains log(observed
scale), and379 is the causal floor choice. There is NO full coordinate-invariance
claim. All sources share obs8/pred12 rawstride12 and the same context predictor.
The audit binds original packet arrays and checks support before registration.

Recordings use unambiguous JSON [source,local_recording] keys so local ID reuse
does not merge different recordings. Query recording is entirely absent from
its reference statistics, retrieval and labels. Namespace qualification also
changes the deterministic permutation salt relative to v1; thus v1/v2 shuffled
numbers are not a paired identical-permutation experiment. Primary v2 controls
share exactly the same reference bank, neighbors and source-record permutations.

## Fixed Calculations

Keep all6contexts x3headseeds x4sources =72 views and the previous original-self
selected cohort. Replay original and estimation-only predictions and selection
hashes before scoring. Inference includes unknown outcomes. No query selection
depends on future support; known donor labels are supervised fitting data only.

For each query recording, feature mean/std use all other eligible, positive-
envelope fitting rows in the four-source bank, including unknown-outcome feature
rows. Neighbor labels use only known donors. Exactly32 Euclidean neighbors,
std floor1e-6, clip8, chunk256 and fixed shuffle seed20261029, no tuning/capping.
Known donor counts by source are reported. Donor-rich sources can dominate;
that is an explicit limitation, not silently balanced after results.

Predict H/envelope and easy-H/envelope, then multiply by each query's own
causal envelope. Do not pool raw cost units. Reference targets are paired and
dimensionless, whereas each source's report retains its own frozen cost scale.
Controls are pooled donor mean and the same nearest neighbors with paired
labels permuted within each source/recording. A missing32-donor bank produces
unsupported NaN, never zero risk. Frozen original B/R/easy-R are copied. Count
B+H envelope exceedances without projection; no policy executes these outputs.

## Measures and Frozen Screen

Same as v1: source-normalized signed-risk MSE on the FULL fixed selection,
equal-view average, harm masses, false-safe counts, conditional AUROC/AP,
known/unknown/support counts and hashes. Unsupported queries keep the primary
view undefined. Unknown labels are outside supervised scores but retained in
inference and denominators of support. No omitted source/seed or retrospective
replacement by a supported subset.

The descriptive information screen requires pooled nearest easy MSE below both
pooled mean and shuffled controls, and at least12/18 context/head-seed pairs
below both when their four source views are averaged. Absolute slack1e-12.
Separately report whether nearest easy MSE is lower than original, not as an
additional success shortcut. A screen pass would mean fitting information,
not calibrated risk, neural contribution, policy utility or independent transfer.
No new held readout or deployment follows automatically. No CI/p-value claim
from one fixed permutation or repeated fitting occurrences.
