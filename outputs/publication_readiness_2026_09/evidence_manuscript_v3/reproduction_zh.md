# 当前论文稿的核验与实验恢复

## 本轮完成的内容

新版英文稿把 SDD 四场景研究与 EuropeanSquares 十二个已暴露开发地点的
后续研究串起来，但不混合数据、单位、指标或置信区间。三张表来自锁定哈希
的公开汇总结果，不是重新训练或重新评估。每个欧洲数据对比保留原文件和
JSON 指针。旧稿和旧实验不改写。

本轮还补读了此前无法访问的 Conformal Policy Control 原文。基线保护、
模型路由、风险阈值本身不能作为新方法证明；现有系统也没有继承该文保证。

## 轻量核验

在项目根目录运行：

```bash
.venv-pytorch/bin/python scripts/build_m3w_evidence_manuscript_v3.py --check
.venv-pytorch/bin/python -m pytest tests/test_m3w_evidence_manuscript_v3.py
```

第一项只读八个已固定哈希的公开结果/协议文件，重建内存中的文稿和表格并
逐字节比对，不读取轨迹、未来标签数组或模型检查点，不连接 CREATE。
不加 `--check` 才写回本目录的四个派生文件。

修改正文时编辑 `manuscript.template.md`，再运行生成器。改变原始实验结果
必须另立有来源的新版本，不能为了生成通过而随意更新锁定哈希。

## 真正训练仍未完成

当前匹配实验计划训练三种辅助监督、共 216 个神经代价头。真实 TRAIN
批次前向/反向检查成功，但实际优化更新为 0。合成数据恢复测试不是真实
训练；当前没有新模型效果可写入论文。

训练与恢复命令以 [实验教程](../european_temporal_auxiliary_v1/reproduction_zh.md)
和 [冻结评估协议](../european_temporal_auxiliary_v1/readout/protocol.md) 为准。
保留原有 10 GiB 磁盘余量，以及检查点总额和原子写入余量。不要为了启动而
放宽保护阈值，不删除其他项目数据。CREATE 连接失败只能说明本次无法观测，
不能推断远端任务失败、排队结束或没有任务。

资源恢复后先进行已注册 pilot，验证真实训练和精确恢复，再运行全部训练。
全部 216 个最终检查点冻结后，才运行已经注册的七组评估。不能用验证表现
回选检查点或阈值，也不能遗漏四个强控制。独立角色仍未开放。

## 结果判读

- E1-E5 是归一化决策分数误差，E6-E9 是归一化逐步误差，不可直接相加。
- E10-E11 是参考代价归一化后的效用差，不是 ADE/FDE 百分比提升。
- 原有选中子集的时间对比仅有 11 个可用地点，不是完整 12 地点结论。
- 改善整体预测误差不等于保护 easy，更不等于外部独立验证通过。
- 当前稿仍非投稿就绪；没有新增部署、Stage5C 或 SMC 执行。
