# Model And Data Card: Coupled Local Costs

Deterministic k32 retrieval predicts five cost proxies for seven frozen
forecast actions. No new parameters, optimizer loss, JEPA, Transformer or
trajectory dynamics is trained. Old neural models are verified inference
references/candidate producers, not newly trained models.

A 398-field physical-action mean descriptor sets distance. This compression
is not a complete test of all possible history representations. Normalizers
are original physical-fitting values. Shared R/ER and convex harm decoding
preserve necessary inequalities, not calibrated confidence guarantees.

**Actual source weighting:** inverse counts are computed on the fixed complete
causal fitting pool before excluding query recordings. They are identical
across controls. Remaining source masses can change after exclusion. This is
source-weighted retrieval, not exact equal-source balancing inside each
leave-one-recording donor bank. No result is silently recomputed differently.

Data are the original six SOURCE fitting contexts, detector midpoints in image
pixels, obs8/pred12/stride12 raw frames. Queries exclude their entire recording
from fitted donor labels; upstream producers and normalizers saw fitting data.
This is not whole-pipeline OOF or independent generalization. Original unknown
labels remain NaN; completion endpoints are proxies, not observations.

No future endpoint/support, central velocity, test goals or test statistics
enters query features. The label-perturbation test proves the scoped retrieval
isolation property, not all upstream lineage claims. Independent roles stay
closed. The primary gains 0.830158% on known fitting ADE but supports 30/444 risk
views; neither it nor the stratified control is deployed. The tiny positive
neural-bank fitting contrast does not override that failure.

Public files are code, aggregate metrics and statistical SVGs. Raw data,
donors, cached arrays, weights and PNGs remain private; a clean public clone
does not contain the assets required for execution. No metric/seconds,
human-gold, true3D, foundation, Stage5C or SMC claim.
