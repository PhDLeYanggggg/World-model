# Anonymous replay for v191

The v22 supplement pairs with the [v191 candidate](../evidence_manuscript_v191_equal_replacements/README.md).
It carries v21 byte for byte and adds anonymous location-level counts,
paired means and resampling indices for the equal-replacement comparison.
Extract the local archive and run `python3 -I -B -S verify.py` from its
directory. No network, training weights or raw labels are required.
The [receipt](receipt.json) binds the archive to the manuscript and
the exact development readout. No files were uploaded to OpenReview.
