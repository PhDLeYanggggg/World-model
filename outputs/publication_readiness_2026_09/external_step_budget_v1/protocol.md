# External stepwise movement matching before outcomes

Use only the original Athens and Swiss past rosters, forecast banks,
and matched proposals. For each joint-vs-control contrast, hold both
arms' two recipients and all waypoint directions fixed. Match the
departure from CV at every step to the minimum of the four original
departures. Compare with the untouched peak-matched proposals and a
uniformly scaled control with the same smaller peak as the stepwise
version. These are separate paired contrasts, not a new ranked menu.

Record movements retained, any degenerate common profiles, and the
full-roster geometric ADE, FDE and relative-path envelopes for each
variant. Average first within each packet, then across seeds and members
inside source group. Do not pool across coordinate systems. Bounds are
label-free absolute limits on the difference in errors, not utility
estimates. Freeze the common profiles before any real external readout.
Exercise the paired metric with fabricated masks and positions, but
export no numerical effects from fabricated targets.

No new external role, threshold, time unit, or main outcome is assigned.
The original two-edit peak-matched comparison and 2% release procedure
stay intact. This is an optional secondary control if scoring of the
corresponding cohort is authorized.
