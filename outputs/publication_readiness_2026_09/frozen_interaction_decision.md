Specified2026-09-20 after the old v6 outcomes and the engineering coupling audit,
before the new geometry-aware independent forecast results. This is post-hoc
development evidence, not preregistered confirmation or a primary amendment.

## Fixed Scope

Reuse all six completed conditioned-context v6 predictors: Transformer and
EqMotion-K1, seeds17/29/43. Evaluate both original ridge/neural cost heads and
both conservative/moderate policies. Reuse only the already opened development
recordings ucy_students01 and ucy_students03, one physical university site.
No source SDD/bookstore, calibration, confirmation or unopened external data.
No retraining, threshold search, model selection or promotion.

The original eight observed/twelve predicted native annotation steps, full-path
ADE, past-derived scale, fixed easy/hard thresholds, support rules, geometry,
solver time budget and devices remain unchanged. Raw-coordinate errors stay
recording-local. The pending primary-metric proposal is not adopted here.
No new raw50 supplement is needed: the present comparison targets the original
full12-step decisions; previous raw50 results remain separate.

## Comparison

For every scene query, issue the frozen forecast and cost scores once; preserve
the original floor, uncontrolled, independent, scene-uniform and joint arms.
Attach versioned numerically checked risk-only independent, unary-geometry
exact-count and full-joint exact-count controls. New joint and unary arms match
the new independent count, before labels. The geometry control removes only
the non-additive binary-product term, not the original predicted-harm budget.
All3new arms use the same scaled/primal-dual-checked solver version.

Verify each query/agent, scale, label mask, floor and uncontrolled forecast error
against the completed original row export. Any prediction/error identity change
stops the diagnostic instead of silently calling it the same predictor. Keep
solver failures/unmatched queries and zero interventions in overall results.
Report count-matched and nonzero matched contrasts separately. Count selected
identities and changed forecasts separately; neither implies equal realized risk.

## Outputs And Interpretation

Report ADE/FDE, all/easy/hard, positive harm, tail/worst-site errors, intervention
rates, proxy values and direct joint-minus-unary differences for every family,
head, policy and seed. Report per-recording native errors. A single physical site
does not support a scene-bootstrap CI; mark it unavailable rather than resampling
windows as independent scenes. Three seed values describe fitting variability,
not external-scene uncertainty. Do not pool duplicated candidate exports as
independent observations. No outcome chooses a new policy.

A joint gain that disappears against unary geometry is not evidence of the
non-additive interaction term. A lower proxy without better forecast utility is
not a dynamics contribution. Unchanged floor performance is not a learned gain.
Even a favorable exploratory contrast requires later independent confirmation.
