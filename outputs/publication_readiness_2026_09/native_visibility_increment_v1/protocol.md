# Factorized Increment At The Same Neural Replacement Count

Keep the exposed Moving A roster, 8/12 native annotation steps,
CV risk reference, OLS4 accuracy comparator and the original 2%
recording checks. Use the same recipients as the frozen motion
selector and match the number of genuine neural replacements
in every query to the previous CV-difference control. Both the
total intervention count and the neural replacement count are
matched. Do not count an identity forecast as a replacement.

Compare the previous CV-difference choices, direct increment
ranked at the same count, minimum path disagreement, and two
factorized scores. The factorized score is
(1 - p_unknown) times predicted gain conditional on available
labels minus p_unknown times maximum paired path disagreement.
Use the same fitted conditional gain in both factorized arms;
only p_unknown differs: donor prevalence or a fitted past-only
row score. The unknown probability describes the released-label
mask, not physical visibility or true future error.

Each of the 42 outer source/seed cells uses the same 13 donor
sources and nested 12-source anchor fits as the direct experiment.
Use source-balanced ridge with the original 0.002 penalty and
query weights. Clip probability to [0,1] and conditional gain
to the pairwise disagreement bound. Rank candidates with stable
ties; no held-source threshold or count choice. Freeze all policy
choices before reading score labels.

The primary contrast is past-only probability versus donor
prevalence at identical counts; compare both to CV difference
and minimum disagreement. Report paired source bootstrap
intervals, available-label utility, completion-lower utility,
observed unknown-prediction Brier score, recording passes and
easy/relative-pair effects. The matched experiment is not a
deployment rule. No new external access, threshold tuning,
Stage5C execution or SMC.
