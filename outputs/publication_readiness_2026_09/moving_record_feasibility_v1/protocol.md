## Exact Diagnostic Condition

For a recording, consider legal known easy rows with positive floor error R.
Let H=max(neural_error-floor_error,0). A nonempty finite-support binary policy
meeting both positive-harm budgets and signed easy-net requirement exists if
and only if at least one such row has H/R <= 0.02.

Necessity: selected easy harm/reference is a reference-weighted average of
the selected known easy H/R ratios. If each exceeds 0.02, no subset can pass.
Unknown selected rows add nonnegative disagreement mass but no observed easy
reference; non-easy rows cannot increase the easy reference denominator.
If there is no positive easy reference, the existing easy-risk ratio is
undefined rather than measured safe zero.

Sufficiency: select just one qualifying easy row and keep every other row
at the floor. All-risk and easy-risk equal its H/R. Signed easy-net increase
is at most H divided by the full recording's easy reference, hence <=0.02.
Choose the smallest H/R witness for the diagnostic only. Verify this witness
against the unchanged original policy evaluator for every required recording.

The condition concerns this fixed binary candidate class and existing label
support. It is not an impossibility theorem for a new forecaster, new actions,
new annotations, a different horizon or a different future protocol. It does
not prove causal learnability when a label-aware witness exists. Labels define
only this oracle diagnosis; no choices, oracle features or row-level label
packets are exported for inference or model training.
