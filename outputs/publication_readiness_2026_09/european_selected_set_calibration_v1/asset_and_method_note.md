# Why This Is a Different Control, Not a New Architecture Claim

The selected-risk-learning round completed72 Torch fits: added fixed-group
supervision lost to matched mean-joint accuracy in five of six intervals and
retained easy-positive-harm failures. Reference protection completed72 matched
continuations, kept reference predictions bit-exact, but did not improve the
primary joint comparison; conditional harm remained underestimated. Subset-excess
and source-policy-selection experiments likewise did not establish a repair.
These routes are not rerun under a new name.

The complete selected-pool diagnostic found6/60 defined screened joint transfer
failures, with9 undefined accepted views. Five failures predate filtering. Sparse
reference overestimation and persistent harm underestimation are different
algebraic patterns, not proven causal classes. Their case IDs/outcomes do not
define the new calibrator, thresholds or inference eligibility.

This control changes only the population on which the fixed empirical residual
adjustments are fitted: repeatedly recompute the actual selected set instead of
training on fixed proxy groups or calibrating once on the raw pool. Whole-recording
OOF can falsify the idea before any new target-transfer run. It does not introduce
a general multicalibration algorithm or prove a cross-domain coverage guarantee.

Prior work checked2October2026: the primary abstract of
[Hebert-Johnson et al., ICML2018](https://proceedings.mlr.press/v80/hebert-johnson18a.html)
defines calibration over computationally identified subpopulations. The primary
abstract of [Fisch et al., arXiv2208.12084v2](https://arxiv.org/abs/2208.12084)
distinguishes accepted-population calibration from accuracy. These ideas precede
this control; our partially observed positive-harm/reference ratio is different,
and no theorem or novelty claim is inherited. This is a bounded diagnostic repair,
not yet a paper method contribution.
