# Frozen Interaction Features: Complete Matched SOURCE Study

This separate addendum records a completed experiment. It has not been inserted
into the current nine-page main PDF; that PDF's scientific content and exact
render receipt remain unchanged.

All nine existing EqMotion predictors were replayed on their original past-only
input packets. Complete extraction processes 1,913,814 forecasts and stores
897,060 h64 rows; a separate complete re-extraction matches every coordinate and
latent. These are repeated features from 149,510 SOURCE windows, not independent
new samples. Build and replay each take about two hours on native arm64 CPU4.

The subsequent experiment trains 36 real Torch cost heads with three actual
seeds, 116,160 primary updates, 4,000 full-refit updates and a 1,200-update recovery
pilot. Interaction64 and Zero64 share 33,349-parameter architecture, initialization,
fitting-only preprocessing, query draws, loss, budgets and the original 2% rule.
All predictions freeze before held policy scores. Actual checkpoint roles are
G-only; all 36 prediction pairs and 72 groups replay exactly.

The mean full-bound fitting objective improves from 1.498058 to 1.326343.
However, the registered paired lower effect is -0.0213 pp [-0.6148, +0.6482],
and the known-label effect is +0.4800 pp [-0.1007, +1.1025]. Neither supports
a held-scene feature improvement. Only 110/444 repeated recording views satisfy
complete risk, with worst easy-net degradation 39.3712%. The CV-relative macro
comparison is also inconclusive, not a claimed strongest-baseline win.

Locality 082 has only 78 whitelist windows, no complete12 future and no valid
final endpoint. The all-required-locality endpoint interval remains not
estimable; no scene is dropped or label imputed. SOURCE is exposed development,
not independent final confirmation. The initial wrong-packet extraction and
zero-update wrong-role preparation failures are retained with explicit repairs;
discarded H-derived preprocessing did not train or select a policy.

The new information bundle also changes raw neighbor coverage. A learned-
encoding-only effect is not identified. There is no new deployment, JEPA lift,
scene-joint contribution, world-dynamics upgrade or submission-ready result.
