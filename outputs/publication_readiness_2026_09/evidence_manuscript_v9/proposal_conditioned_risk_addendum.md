After the public regression-deferral comparison, I tested whether a cost critic
trained only on actions proposed by a source-excluded router would improve
admission safety. Router A, critic-fitting B and validation V use disjoint
original inner-C source partitions. The architecture, initialization, fitted
preprocessing, query draws, 2,000-update budget and original2% risk veto match
the all-action critic control; only the supervised action mask changes.
