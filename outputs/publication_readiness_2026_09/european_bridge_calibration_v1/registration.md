## Material Passport

then fresh frozen readout on six reused opened model-selection localities.
No new neural training or independent risk guarantee. Register before source-C
calibration; freeze all maps/actions before the new selection-outcome readout.

## Question and Difference from Earlier Calibration
Attribution found no stable neural ranking advantage at matched query coverage.
Does fixing reference-aligned moment scaling or selected-risk calibration repair
positive-harm reliability while retaining useful forecast selection? Earlier
nested calibration used CV-to-candidate pairs; the current paired delivered
policies differ. Reusing its numeric calibration factors would be invalid.

Keep all18 producer/controller/seed configurations, both full/motion-only pairs
and neural/ridge scoring. A produces the complete forecast/floor chain; B fits
the utility/risk heads; C is the remaining disjoint four-locality source roster.
Every calibration label and transform uses C only. The same fixed A/B system
predicts C and the six readout localities. All source localities are historically
opened development data, so C is producer-excluded, not a newly independent test.
No best source assignment, seed, new model or deployment is selected.

## Four Frozen Rules Per Pair/Family
- Reference-only: structural abstention from R-to-P changes.
- None: existing positive-utility, moving, nonidentical-rollout and0.02 ratio gate.
- Population rescale: equal-locality C moment means; increase harm multiplier
  only, decrease reference multiplier only. Unsupported moments abstain.
- Selected-risk grid: fixed cutoffs0,.001,...,.020, plus structural abstention.
  Require every C locality's all-event and positive-CV-easy positive-harm/R-error
  ratios <=.02, net CV-easy degradation <=2%, and zero added error on CV-zero
  rows. Easy/hard cutoffs stay A-derived, not R-derived. Missing event support
  is undefined, never passed. Among feasible rules choose highest equal-locality
  ADE gain over R; ties prefer fewer actions then smaller cutoff. No positive
  feasible gain means structural fallback. Cutoff0 is not structural fallback.

These are empirical calibration rules, not conformal/LTT certificates. No risk
tolerance or outcome definition changes. The old source calibration algorithm
cannot be reused unchanged because its easy event and denominator were both CV;
here the event is CV-defined and the denominator is the delivered R policy.

For diagnostics only, fit the grid on each three-of-four C subset and report
the held-C locality. Do not use this diagnostic to select a different final
rule, tune thresholds or change confidence. Preserve negative transport.

## Finite-Scene Feasibility
Report assumptions for any future independent calibration. Include zero-event
binomial upper bounds for4/6/12/24/60/150 hypothetical independent localities
at delta=.10/.05/.01. They concern probability of a violating locality, NOT
mean ADE harm ratio. Also show the best-case HB p-value for a hypothetical
