# Admissibility control: a small known effect without safe-policy gain

We test a structural restriction in the frozen-risk decoder. The original rule
admits only individually positive predicted utility actions. The enlarged rule
can include a nonpositive-utility action if the selected combination has
nonnegative utility and satisfies both unchanged2% positive-harm/reference
constraints. The same forecasts,cost estimates and causal availability are
retained;benefit never offsets positive harm in a risk numerator. The primary
pair has identical intervention count in each contemporaneous query.

The label-side mechanism check is particularly informative. Both unrestricted
and true-positive-action-restricted oracles have positive supported solutions

admissibility can matter abstractly,but the actual fitting-label opportunity
does not require this enlargement. This control does not support the proposed
restriction as the core empirical bottleneck or demonstrate causal learnability.
