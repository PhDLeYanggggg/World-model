# Stop Now Or Wait One Eligible Query

Use the same Moving A eight-observation/twelve-prediction image-space
bank, original controller and original realized 2% risk contract. The
earlier opening diagnostic found 9 first-query, 6 later-only and 3
no-positive-candidate views among 18 original zero-switch views. This
is exposed development, not a new primary benchmark or independent test.

For each held-source fold and forecaster seed, reuse the seven fitting
sources and six disjoint calibration sources. Keep joint easy-support
ranking fixed in both policy arms. Obtain fitting features with inner
source-excluded original cost and joint ranking fits. Give the top
ranked candidate reward +1 for a positive standalone supported action,
0 for supported without positive gain, -1 for unsupported. Fit a
source/recording-balanced ridge stop value. Fit continuation using the
realized reward at the next eligible query if an inner source-excluded
stop head there would act, otherwise zero. The continuation target is
not the maximum observed reward across future queries. Both targets use
fitting labels only. Missing or terminated continuation has zero reward.

Compare: stop at the first eligible query if the stop value clears the
threshold; or at that query compare stop with continuation, take the
better action, and if waiting, allow at most one subsequent eligible
query before abstaining. The original direct actions are preserved.
Never open after direct has already intervened. The next query's
features are not available for the first decision. Both rules use
the same threshold grid and same full-policy preservation criterion as
the previous opening study, on calibration sources only.

Primary: calibrated stop-wait versus calibrated first-stop and direct
on all 102 held-development views, including whole-source paired
completion-lower intervals, counts, and original risk failures. Also
report unthresholded first-stop and stop-wait as diagnostics, their
counts and the 18 zero-direct views. Do not use posthoc opportunity
classes for fitting or selection. No independent labels, new forecast
training, deployment, Stage5C or SMC.
