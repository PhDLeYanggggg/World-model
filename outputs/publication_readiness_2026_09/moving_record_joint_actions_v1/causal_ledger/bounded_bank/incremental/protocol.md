# Learn The Cost Of Enlarging A Switch

Hold fixed every intervened row and forecast family from the previously
registered bounded-bank matched policy. A refit can only lower that row's
existing amplitude (quarter, half, full); it cannot change the population,
turn a switch into exact CV, or spend slack from future queries.

For each candidate fit the adjacent increments quarter to half and half
to full. Targets are paired differences of conservative ADE utility,
all positive harm, and easy positive harm. Existing missing-target radius
is included in each absolute term. The model is ridge 0.002, trained without
the evaluated source on the original source and query weights; inputs use
the upper action's original causal descriptors. Project predictions using
the maximum distance between the adjacent paths (and easy harm no greater
than all harm). The frozen decision score is cumulative predicted gain
minus all and easy added harm, relative to the quarter path. Ties favor the
smaller amplitude. These are model scores, not new safety thresholds.

Controls: original, uniform quarter of every selected forecast, and a
downward-only policy with the same score derived by differencing the
existing absolute cost predictions. Primary identification contrast:
the direct incremental model against that independent ranker constrained
to the exact same final amplitude multiset in each current query. The
same two rows and forecast families remain fixed. If a query has only one
possible assignment it contributes no contrast; report exchangeable counts
and full-roster statistics, never call an empty contrast a pass. Also
compare the unconstrained independent ranker to show the practical
tradeoff and report prediction errors on the original selected arms.

All 102 exposed development views and three verified forecast bank seeds.
Use 3,000 paired source-bootstrap draws and existing completion-aware ADE,
selected-reference risk and easy signed net rules. Reducing amplitude at
fixed rows can only reduce the positive-harm numerator, but it need not
improve signed net error, ranking or risk support. No change to the original
2% rules, independent roles, forecasting backbone or deployment.
