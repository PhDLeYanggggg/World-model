# Learn The Difference Between Rejected And Repaired Sets

Reuse the three frozen forecast banks, fixed Moving A roster and nested
held/donor exclusions. Regenerate the same donor teacher decisions:
predicted utility is fitted without either source; the donor's outcomes
are used only to obtain the observed-budget repair. Learn only from
queries where the rejected and repaired sets differ. The target is a
unit preference for the repair. Fit ridge 0.002 to their feature
difference with equal active donor weights and equal changed-query
weights within donor. This is a comparative decision model, not a
calibrated risk estimate.

Both variants average the original action descriptors in forecast-family
blocks. The interaction variant adds the mixed relative-path change:
both replacements minus each individual replacement plus neither.
It uses min, mean and terminal separation and reciprocal proximity in
past-scaled image coordinates, without outcome inputs. The interaction
is zero with only one switch. The membership control is the existing
constrained student fitted on the same doubly excluded donor proposals.

Compare original and three learned objectives over a shared, causal
slate. Keep the original exact per-query count. Collect the 16 highest
estimated utility and 16 lowest estimates in each of the all/easy costs,
plus the original actions, then enumerate distinct-row sets of size
one or two. Keep only options whose predicted all and easy spend are
both no greater than the original set's current spend; always include
the original. This preserves its predicted accounting without future
queries. The slate restriction is part of this test and is not a full
optimization result. Report how often the choice is nontrivial.

Primary: interaction set score vs additive set score on the same slate.
Secondary: additive vs membership, each vs original, original observed
2% risk and support, hard utility and observed local relative error.
All 102 views, source-paired 3,000 bootstrap draws after seed averaging.
No model selection on the independent data, change to evaluation rules,
deployment, Stage5C, or SMC.
