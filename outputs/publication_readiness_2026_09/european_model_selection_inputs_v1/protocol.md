## Exact Observation Schema

Keep the existing8observations/12requested outputs/rawstride12, raw box-center
point convention, per-recording256query-frame cap and all currently visible
agents. Full8-step past support determines targets; short-history agents remain
as context. The evenly spaced query grid uses past-support indices, never
future completeness, track survival or prediction errors. Retrospective grid

Only input/query-index arrays are constructed: history boxes/centers/masks,
causal finite-difference velocity, target eligibility, legal CV forecast and

reads complete released recordings for hash verification; this is not a claim
that the file bytes contain no future observations.

Unit tests compare exact existing input semantics and mutate/truncate future
rows. Real first/middle/last query inputs are compared against the independent
raw-prefix reader. A second complete raw reparse must reproduce every stored
input/index array and original role/row hashes. These checks are engineering
and causal-input evidence, not model generalization results.
