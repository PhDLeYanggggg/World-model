# 本轮训练与复核操作

## 已核验结果

六个分支和 48,000 步全部完成，完整运行日志跨度约 37.02 分钟。
24 个保存点精确重放；完成后再次运行未增加训练，290 个文件哈希保持不变。
32 项针对性测试通过，完整旧测试集未重跑。

直接期望误差模型三个种子全部回退，提升为零。增益监督后平均训练提升为
0.2339%，旧密集预测对照为 0.1872%。这个微小差异主要来自减少 easy 伤害，
候选轨迹本身并没有更强，hard 提升反而低于旧对照。deathCircle 训练场景
三个种子都仍为负。不能因此宣布新的动力学贡献、独立泛化成功或可部署。
完整结论见 [conclusions.md](conclusions.md)，所有结果见 [results.md](results.md)。

## 这一轮在做什么

给已有轨迹网络增加一个真正可以返回基线的选择头，比较两种固定损失。
一种直接最小化选择后的期望误差；另一种同时监督候选相对基线的增益，
并保留候选轨迹自身的学习梯度。不能把全部回退、零提升说成预测成功。

本轮使用全部 15,430 个指定源训练样本，不是抽一小批做演示。
三个种子、两种损失，共新增 48,000 步；最初试跑的 100 步计入预算。
三个旧的同预算密集预测对照经过核验复用，不算本轮新训练。

## 环境与恢复

在项目目录使用 `.venv-pytorch/bin/python`，不要用 Intel Conda 或 Rosetta。
保持计算线程 4、进程间线程 1、数据加载 worker 0。每 200 步保存原子
checkpoint 和 heartbeat，包含参数、优化器、采样器及随机数状态。

运行入口和完整命令见 [英文复现指南](reproducibility.md)。重新运行训练入口
即可从已有 checkpoint 恢复。启动前先查看私有运行目录中的 `heartbeat.json`
及 `training.log`，确认原进程已退出；不要让两个进程同时写同一目录。
完成后重复入口应只核验，不新增训练。退出码为零仍需检查产物与数值。

私有运行目录：`data/stage_cvpr2027_experiments/source_cost_deferral_v1/`。
公开结果目录：`outputs/publication_readiness_2026_09/source_cost_deferral_v1/`。
本地性能足以完成该预算，本轮没有提交 CREATE 作业，也没有核实远程当前状态。

## 怎样读结果

- `proposal`：不经过新门控的候选轨迹是否学得更好。
- `hard_action`：按预先固定的分数大于零规则介入，否则精确回退的结果。
- `expected_action_risk`：训练用软期望风险，不是实际输出轨迹的误差。
- `actual_changed_rate`：真正改变基线预测的比例，不只是请求介入的比例。
- `easy_pixel_harm`：零误差基线样本受到的绝对像素伤害。这些样本的相对
  退化百分比没有定义，不能将其写成通过原有的 2% gate。

所有分支都报告，不能选择一个训练快照充当新的部署模型。训练集拟合好，
也不代表新场景泛化好。源场景保留集、本项目主验证/校准/确认数据本轮不评价。
历史测试集参与选择及数据血缘问题不会因为重跑这个实验而自动消失。

本轮不是新的 JEPA/Transformer 训练，也不检验 RGB 的额外价值。
原始数据、图片、checkpoint、逐行预测不上传 GitHub。只同步代码、配置、
汇总结果和原创统计图。不执行 Stage5C，不启用 SMC，不声称米、秒或 true 3D。
