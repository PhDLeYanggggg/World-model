## Loss, Not An Inference Input

Retain original five-moment normalized regression plus0.5gain-error objective.
For each Cfit, freeze the existing same-seed teacher's causal independent action
choice. These are supervised-training Cteacher decisions, NOT source-OOF
validation or independent calibration. No teacher future endpoint/label/mask
is an inference feature. Teacher masks and recording IDs enter the loss only.

On each original72query batch, the network still pools only within current
queries. Aggregate cost residuals at the fixed teacher action by recording:
all-excess error = sum(scale*(predH-trueH-.02*(predR-trueR)))/sum(scale);
easy-excess error = sum(scale*(predEH-trueEH-.02*(predER-trueER)))/sum(scale).
Here pred/true moments are in normalized causal-scale units; scale weighting
restores raw recording mass before the explicit normalization. Divide each
excess by sqrt(rmsH^2+.02^2*rmsR^2), or its easy analogue. Average their squares
within recordings, then average active recordings within source, then sources.
Add this term with fixed weight1. No positive/negative asymmetry or loss search.

These are sampled-batch recording aggregates, not a full-record event guarantee
or an unbiased full-video squared-loss estimator. Cyclic query duplication and
teacher-to-new-policy selection shift are limitations. Inactive sampled
recordings contribute no term, not a fabricated safe zero. Whole-unknown rows
use the previously approved conservative moment targets, not observed-zero
future labels. R/ER candidate invariance and coherent cost envelope constraints
remain the unchanged CostHead, not a new architectural contribution.
