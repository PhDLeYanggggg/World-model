# Recipient Access At A Fixed Query Budget

The previous twelve whole-query options add OLS4 and a common
translation to four fixed proposals. This readout tests whether
pairing, path availability, or recipient availability explains the
remaining capacity deficit. The largest permitted intervention count
at each query is the actual shared count of the four original choices.
An oracle may make fewer switches, as it could previously abstain.

1. Recombine only recipient-path pairs present in the twelve options,
   without requiring the original pair of recipients to stay together.
2. Keep the same union of recipients but give each the full original
   causal/neural forecast bank plus the common translation.
3. Allow those same forecasts for all original query recipients.

Keep CV as risk reference/fallback, OLS4 as accuracy comparator, equal
query weights, missing-outcome charges, positive easy support, and the
original 2% risk checks. The objective is conservative utility, not an
interaction proxy. Minimum-error legal paths on known rows dominate
all other paths for the same row; keep all legal unknown alternatives.
Allow four seconds per recording solve. Verify every solution with the
original scorer and retain unresolved cases. Compare positive and
feasible transitions at each nested expansion on the same 34 exposed
Moving A recordings (14 sources and three seeds, 102 dependent views).
No fit, no learned action choices, no externally held data or outcomes.
