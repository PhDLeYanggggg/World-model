# Can a causal pass-transition model transfer to a different dataset?

Train only on previously exposed OpenDD development sources. Predict
whether replacing one original recipient by an unedited agent in the
same query newly qualifies or destroys an originally qualified recording.
The incoming path follows the observed OLS4 direction with the outgoing
peak displacement. Both datasets use the same frozen 4-by-8 shortlist
rule, input features, exact per-query count and peak radius multiset.
Other original forecasts do not change. Allow at most one exchange per
recording, committed at the first eligible query without end knowledge.

The head jointly learns three transition outcomes and conservative
paired gain. The transition rule requires net predicted qualification
probability above 0.02 and predicted normalized gain above -0.005.
The gain rule uses the same head and requires gain above 0.005. A matched
attribution ranks only by predicted gain at the exact transition queries.
Include the unchanged anchor and causal OLS4-agreement exchange control.
Thresholds are fixed, not independently calibrated.

For OpenDD, fit three seeds at each held location from double-excluded
donor slots. For zero-shot, train three additional models from all seven
OpenDD sources using donor clocks excluding each candidate's own source
and the next site in the fixed site ordering. Apply each seed to the
corresponding frozen MovingDroneCrowd++ fitting-source rotations, not
Moving A. Do not fit any Moving labels or open their separate calibration
or confirmation roles beyond the already exposed rotating held roles.
Use each domain's registered conservative utility aggregation and original
recording risk checks. No dataset coordinate or physical-time pooling.

Freeze predictions before scoring. Report paired source bootstrap
intervals after averaging seeds, exact retained budgets, qualification
gains and losses, tail and selected easy reference. Quantify the exact
one-exchange hindsight capacity with the unchanged scorer, not as a
model result. No deployment, independent confirmation, Stage5C or SMC.
