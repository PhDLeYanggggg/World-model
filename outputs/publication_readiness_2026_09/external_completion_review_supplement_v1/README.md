# Anonymous aggregate replay v20

`data/stage_cvpr2027_experiments/submission_admin/review_supplement_v20.zip`
keeps v19 byte for byte and adds the Songdo componentwise completion
and sampling analysis. It checks the WEPDTOF completion envelope in
the inherited replay. The [receipt](receipt.json) binds the archive
to the v190 manuscript and source scalars.

Extract to an empty directory and run `python3 -I -B -S verify.py`.
No raw annotations or model checkpoints are included.
