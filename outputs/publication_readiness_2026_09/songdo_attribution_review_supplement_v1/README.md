# v23: anonymous Songdo attribution replay

The v23 archive accompanies the [v192 manuscript](../evidence_manuscript_v192_songdo_attribution/README.md)
and includes v22 byte for byte. The added panel sums the three
recipient contributions, recomputes the paired source bootstrap, and
checks the total against the existing Songdo result. It contains only
anonymous grouped scalars and resampling indices.

Extract the local archive and run `python3 -I -B -S verify.py` from
the extracted directory. The [receipt](receipt.json) binds the
archive, original attribution and companion PDF. Neither the archive
nor the paper was uploaded.
