# 本轮实验结果与复现说明

## 实际做了什么

本轮不是只读取旧报告。完成了12个全新神经网络训练，4个内部留出场景、
3个随机种子，共120,000次参数更新，主训练约94.37分钟。
旧的12个无条件训练模型经过哈希核验，作为配对对照，没有算作本轮新训练。

唯一改变：未来监督轨迹完全为零时，不让这一行贡献ADE梯度。
采样顺序、训练行、初始化种子、模型、训练时长、归一化和评价行均保持一致。
未来标签只决定监督损失，不能进入推理输入，也不能用于部署时选择样本。

## 结论

| 指标 | 原对照 | 本轮修改 |
| --- | ---: | ---: |
| 实际跨场景ADE提升率 | -5.02% | -98.72% |
| 看过未来才能挑选的oracle提升率 | +0.47% | +3.76% |
| 非零未来标签子集提升率 | -0.93% | -32.39% |
| 静止未来标签的额外ADE，标注像素 | 0.0919 | 1.4288 |

本轮修改失败，不部署。-98.72%是相对提升率，表示误差约为基线的1.99倍，
不是负的距离。静止子集基线误差为零，百分比退化没有定义，不能说通过2%门槛。

额外的方向对照也很重要：不改变预测长度，只旋转方向，oracle仍达到
3.31%-3.58%。原方向相对三个旋转对照的优势较小，其中一个区间跨零。
因此，不能把oracle增长全部解释成学到了正确方向。这项诊断在训练过程中
单独登记，明确是事后诊断，不包装成原先预注册的主要结果。

## 本地运行与中断恢复

在项目目录使用原生arm64的`.venv-pytorch/bin/python`，不要用x86 Conda。
计算线程4、DataLoader worker0；每200步保存checkpoint和heartbeat。
运行`reproducibility.md`中的正常训练命令即可自动恢复，不需要另加resume参数。
先确认没有同一任务仍在运行，不要重复启动；已完成后再运行必须是0次新更新。

本次12个模型的训练/留出预测全部精确重放；恢复检查保持68个产物不变；
96次加载后未来标签污染检查通过；34项针对性测试通过。
没有重跑会训练并改写历史报告的整个旧测试集。CREATE当前任务状态未核实，
本轮没有提交远程作业。Git不包含数据、逐行缓存、权重、视频图像或虚拟环境。
