## DUT

The dataset authors provide both raw and filtered trajectories, describe intended
model calibration/verification uses, and request citation. Their paper and pinned
README identify two natural campus locations. I accept the unfiltered release for
this project's local, non-commercial calibration research, with attribution and
without redistribution of source files. This is a scoped project-use decision,
not a new license from the dataset owner. No general redistribution license was
found in the previously inventoried pinned repository; sharing data or trained
weights will need its own conditions review. The paper's IEEE notice concerns
the article and is not treated as a dataset license.
[Author paper](https://arxiv.org/abs/1902.00487v2),
[pinned README](https://raw.githubusercontent.com/dongfang-steven-yang/vci-dataset-dut/80b8c746833664cd1e5244fccad79c7f2a7cbe31/README.md).

Do not use upstream filtered velocities as official causal features. Earlier code
inspection identified future-assisted initialization; the local adapter uses raw
positions and its own backward differences. Raw-coordinate units remain unresolved
between README wording and the conversion code, so this review does not authorize
metric or seconds-level reporting. `dut_intersection_04` remains quarantined.

## DroneCrowd

The downloaded official release README explicitly limits use to academic and
non-commercial purposes. The project falls within that declared purpose. I accept
the audited original XML for local, attributed external-confirmation research,
without redistributing annotations or images. The official repository supplies the
dataset and citation. This does not authorize commercial use, waive source removal
requests, or establish an unrestricted redistribution license.
[Official repository and dataset link](https://github.com/VisDrone/DroneCrowd).

Keep the entire source reserved for confirmation. The release's official split
is not a verified physical-site split. Original XML is used under the already
recorded offline-annotation observation mode; source interpolation provenance is
still unresolved. Neither head-box centers nor image-image registration establish
world-coordinate calibration or sensor-time observations.

## Required Gates Remain Separate

This disposition can be bound as source-use evidence in a later experiment
record. It is deliberately not wired to open labels or relax reservations now.
Historical predictive exposure, geographic overlap with other sources, the complete
fitted producer chain, source-specific input/label adapters, fixed policy family,
small-support calibration limits and one-shot confirmation remain explicit gates.
The current source-only refits neither read nor fit these reserved collections.

Use the dataset authors' source links in reproduction instructions instead of
bundling third-party material. Public artifacts are code, configurations, source
hashes and aggregate results. No newly downloaded third-party program is executed
by this source-use review. Existing pinned EqMotion core use belongs to the separate
registered comparator experiment and is not a new data-provider code authorization.
