# DroneCrowd One-Shot Confirmation

This protocol is fixed before the 15-group calibration result. Use only
the approved 30-group, 72-recording confirmation role. There are 216
recording-seed views from three actual forecaster fits, not 216
independent recordings or 30 verified physical sites. Native observations
and forecasts are 8/12 annotation steps in image pixels.

Do not open any confirmation recording through this runner unless the
complete calibration result and its exact replay bind the registered
calibration rule and produce an eligible threshold. Freeze and commit that
choice separately. Use the same fixed causal features, exact predictors,
controller coefficients, reference cuts and original 2% recording
requirements. No policy, threshold or baseline selection on confirmation.

Primary readout: report paired completion-lower utility for the selected
policy versus CV (risk reference) and fitting-selected OLS4 (accuracy
comparator). A positive independent forecast claim requires positive lower
95% interval endpoints for both and all 216 recording-seed views passing
the original risk/support checks. Reuse the original scorer and do not
certify abstention or undefined risk. Report known-only estimates, upper
completion bounds, switch counts, signed easy degradation, worst-recording
p95 ADE, and available-endpoint FDE with its support. The latter is not
full-roster FDE.

On the selected policy's active queries only, compare independent-agent,
shared-family and pair-additive options at identical query intervention
counts. These controls isolate utility and relative geometry, not risk
admission. An empty or unsupported matched comparison is not estimable;
never use it to certify a recording. The stronger joint claim additionally
requires positive paired lower utility versus all three controls and a
positive lower-bound paired relative ADE comparison versus additive.
Use 3,000 paired exclusion-group draws, after averaging seeds.

Seal the whole inference roster before the label readout. Write a bound
opening receipt, then score each recording to a resumable statistics
checkpoint. Once complete, replay only those same statistics. There is no
second selection or reopening of labels for an alternative model.
An empirical pass is not a physical-safety claim or submission approval.
