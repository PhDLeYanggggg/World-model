# v33 anonymous evidence replay

The archive recomputes the Songdo paired budget sensitivity over
14 anonymous source components and 3,000 paired draws. It preserves
the v32 replay, including its matched public-model appendix.
No trajectory, weight or identifying data is included.

The local file is
`data/stage_cvpr2027_experiments/submission_admin/review_supplement_v33.zip`.
Unpack it and run `python3 -I -B -S verify.py`.
