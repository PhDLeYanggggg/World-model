# Risk-Control Positioning Check

Fresh primary-source check,6November2026; no model or evaluation change.

Nonmonotonicity is not a new M3W contribution or a general impossibility result.
Theorem1 in [Angelopoulos,Conformal Risk Control for Non-Monotonic Losses](https://arxiv.org/html/2602.20151v1)
uses exchangeability,symmetric algorithms and an appropriate stability/reference
condition. Its proof does not require boundedness; later stability results add
conditions. Section2.2.1's discretized bounded-loss construction assumes an
everywhere-safe option. Section2.2.3 studies selective classification,not an
automatic certificate for arbitrary trajectory substitution.

For this project,the original selected-reference risk is undefined under empty
support. The physical floor therefore cannot be inserted as a defined zero-loss
safe option without changing the approved contract. We have not done so.
Nor have we proved algorithmic stability,exchangeability at independent source
level,or transfer from an expected-loss statement to every required recording.
An empirical2%check and an exploratory bootstrap are not those guarantees.

This confirms the existing manuscript's limited positioning. It does not change
the compiled main paper,certify the current policy,excuse negative performance
or prove the task impossible. The current four-cell experiment remains a
model-side repair under the unchanged evaluation rules.
