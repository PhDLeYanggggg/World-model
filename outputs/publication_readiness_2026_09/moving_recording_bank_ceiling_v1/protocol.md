# Can Existing Complementary Forecasts Supply The Missing Easy Support?

After the fixed binary bank's 91/102 free-count result, test nested existing
forecast banks on all the same exposed A rows. No new fitting and no future
outcomes used to construct any path. No thresholds, labels or actions changed
in a real model. The oracle uses labels only for the diagnostic allocation.

Compare fixed CV floor plus (1) EqMotion; (2) EqMotion and PCT; (3) both learned
paths plus the five non-CV causal rollouts in the earlier baseline table. All
three actual seed banks are retained. Optimize the exact original free-count
recording problem, at most one non-CV action per row. All known nonharmful
rows can take their best action. A missing easy reference can be supplied only
by a real distinct action whose own easy harm ratio is within 2%; among such
anchors choose minimum weighted utility cost. No unknown action can improve
the objective or relax any risk constraint. Replay the original binary values
and check every witness against the unmodified original scorer.

Report full-roster paired gain only when every original recording/seed view
is feasible. Preserve all failures, and report counts by candidate family
only, never oracle row choices. This is an upper diagnostic for learning an
adaptive allocator, not a trained selector, new trajectory architecture, or
proof of generalization. No external outcomes, scientific role changes,
metric/seconds claims, deployment, Stage5C or SMC.
