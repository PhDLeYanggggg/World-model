\paragraph{Separating timing from coordination.}
We replay the frozen value heads without fitting. The same-query
independent control and the split schedule share the first emitted
path; the split schedule uses the next eligible query for the
second. Moving the second edit later changes conservative utility by
\CrossTiming{} on \CrossCommon{} recording-seed views where both
complete two edits. The full-roster joint pass count rises from
\CrossSamePass{} to \CrossSplitPass{}, but this is not a matched
utility gain; \CrossIncomplete{} split schedules never complete.

In a separate comparison, the first two eligible single-edit queries
fix both clocks. Adding the first edit's estimated gain and risk
before choosing the second changes conservative utility by
\CrossJoint{} at \CrossEdits{} edits per arm. The original recording
check and both reference gains hold on \CrossJointPass{} versus
\CrossIndependentPass{} views. With the first edit fixed, hindsight
can find a qualifying second edit at the next eligible query in
\CrossNext{} credit-starved views, or in \CrossAny{} if any later
query is allowed. These are development comparisons; the original
risk rule and sealed confirmation are unchanged.
