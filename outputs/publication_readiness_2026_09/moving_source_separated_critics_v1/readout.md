## Controlled Model Change

Each single C part supplies two 28,229-parameter cost heads. Means, scales, target RMS and bias use only that own fitting part. For a held C part, the other two provide proposer/risk roles in both orientations. Same-data critics use the other cost seed on the proposer fitting part. Disjoint-data critics use different source groups, but are not statistically independent: forecaster, architecture and dataset family are shared. Less fitting data is a cost of this design. Vetoes retain an original action or reject it; no amplitude reselection or new threshold search. Matching counts AND amplitude histograms removes the prior count-only severity-composition issue, not displacement magnitude differences.
