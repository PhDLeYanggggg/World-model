# 本轮结论

遵从“保持原规则，先改模型”：没有加入恒等回退认证，没有放宽2%门槛，
没有删掉失败或不可估视图，没有重新打开H调参。

真正训练了108个神经成本头，保存216000次主训练更新。提案头与风险头
使用不同来源的数据，各自只用自己的训练数据计算归一化。所有模型训练
冻结后才读取新的内层验证结果，不是训练中挑一个最好看的结果。

但这次没有修复成功。分来源策略有18/276个必要视图的同数量、同幅度
对照为空，主要指标继续不可估。完整策略的次指标也为负：已知标签效用
差值为-0.563个百分点，95%区间[-1.095,-0.193]。减少的伤害为0.213个
百分点，却丢掉0.776个百分点的收益；这两个分解使用相同分母。

风险也没过：只有44/696个录像视图满足原风险与支持要求。
最差已定义录像的easy净退化为477.76%，这不是全体平均值。
对选择出的同一批已知样本，实际伤害和easy伤害质量分别约为风险头预测的
122.85倍和553.27倍。
这不是只缺少分母的问题，还有大量可计算的真实风险超标。上述倍数是
重复样本上的描述性统计，不是置信保证。

训练中断过一次，原因和退出码不明。已核实旧进程消失后，从第100次
更新的检查点恢复；71个完整模型没有重训。主训练累计保存的拟合时间
约2小时27分钟，中间未观测的墙钟间隔不计为计算时间。

216个预测数组、108组策略和1620个成本统计均精确重放，20项针对性测试
通过。另一个只读复核入口也真实运行通过，不覆盖已有公开结果：

```sh
.venv-pytorch/bin/python scripts/replay_m3w_source_separated_critics.py
```

它需要本机合法数据和检查点。权重在私有数据目录，不在Git中。
本轮不升级部署，不宣称A会投稿候选，不执行Stage5C，不启用SMC。
下一步模型假设是显式区分“会不会产生正伤害”和“产生后伤害有多大”，
但尚未训练，不能当作已有提升。
