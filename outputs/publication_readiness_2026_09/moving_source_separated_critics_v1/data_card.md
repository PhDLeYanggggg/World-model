# Data Card: Frozen Moving SOURCE Development Population

**cached_verified:** the existing MovingDroneCrowd++ SOURCE admission,
forecast caches, original outer P/C/H roles and registered three-way inner-C
source mapping. **fresh_run:** own-source critic fits, nested-C inference,
policy scoring and repeated exact replay. **not_run:** new held-out H scoring,
independent confirmation, reserved-source opening or external deployment.

There are 64 admitted recordings and 195,286 past-eligible target windows.
Only 58 recordings in 23 source groups support the fixed task. The original
24-source primary remains not estimable because one declared group has no
usable target window. Supported-group analysis does not silently replace it.

Observation eight and prediction twelve refer to native annotation order.
Pixel coordinates are not verified metric coordinates. Sensor-as-of time,
FPS-to-time interpretation, homography and metric scale are not established
by this experiment. No seconds-level or physical-world safety claim follows.

Provided annotations and their valid masks define available-label ADE.
Partial labels are not complete 12-step ground truth. Wholly unknown outcomes
retain the registered causal disagreement-bound treatment. Endpoint errors
are available-endpoint diagnostics. Derived risk/easy labels and automatic
audits are not human-gold certification.

For every outer context, producer P, critic C and outer H remain unchanged.
The existing inner-C mapping is reused: single parts supply separate fitting
sources, with another part excluded for nested validation. The reader's
temporary routing metadata does not rename those rows as a new official H.
Each source appears in repeated producer/seed/orientation views; 276 source
views and 696 recording views are not independent sample counts. Bootstrap
uses 23 source groups after averaging, not individual overlapping windows.
Physical-site IID assumptions have not been verified.

Every fit's labels, learned means/stds, RMS and initial bias are restricted to
its own part. Future coordinates and masks are supervision/scoring only.
Inference does not consume future endpoints, central velocity, future goal
labels, test-derived normalization or test endpoint goals. No new endpoint
goal construction occurs in this study.

Required empty controls remain unavailable. For the source-disjoint policy,
18 source views have no matched intervention, 173 recording views have
undefined selected easy risk, and 30 views have zero full known easy reference.
These are distinct levels of support; counts overlap and must not be summed.
No view is removed and no identity-fallback certification is added.

Raw data, large feature/history/latent caches, weights and per-agent action
caches remain outside Git. The public repository contains code, definitions,
hash receipts, aggregate metrics and reports only. Existing unrelated staged
data-lake files are not part of this study's commits.
