This protocol follows the completed supporting selection forecast readout.
That readout's known history-input effect is positive, but its completion-lower

are already exposed; this comparison is development/model selection, not final
confirmation. Risk calibration, confirmation and DroneCrowd remain closed.

## Hypothesis And Specific Change

A useful forecast does not decide when to intervene. Fit a cost controller on
the original149,510-row SOURCE controller whitelist, using only the eight SOURCE
localities excluded from each frozen forecaster's four fitting localities. This
provides out-of-producer-fit cost labels without fitting a controller on new
selection outcomes. All nine actual history producers (three folds and actual
training seeds17/29/43) remain. No old head or teacher is promoted to clean evidence.

Compare matched row and same-query-context critics from identical initialization.
Both use380causal motion/rollout fields plus64past detector fields. No static
scene polygon, scene ID, goal, future endpoint, future availability, central
velocity or test statistic enters the input. The context arm adds the mean
hidden representation of other forecast-target agents at that exact same
recording/frame; the row arm does not. Both have the same active parameter set,
decoder, complete source-balanced query draws and coverage budget. Context
pooling adds no parameters. A singleton has identical representation in both.
Existing partial observed neighbors already remain inside each row's features;
query context is not a claim that every visible agent receives a forecast.

Predict coherent benefit, positive harm, reference, easy-reference and easy-harm
moments for six causal physical candidates and one fixed actual history forecast.
Reference and easy-reference are shared across actions. Benefit is capped by
reference; harm+uncapped benefit is bounded by causal disagreement; easy harm
is capped by harm. Use the existing known-only4x underharm squared objective
and0.5within-row relative-utility loss, averaged within queries. This reuses
established cost learning; it is not a new proper scoring rule or new dynamics.
Unknown labels stay unsupervised but their causal rows remain query context.

Feature statistics are SOURCE-only, source-balanced and physical-candidate-only.
RMS/bias use SOURCE fitting labels only. No selection normalization or threshold
search. Query sampler visits every original fitting query at least four times;
the budget is max(2000,4*ceil(largest_source_queries/4)). Each batch contains
four complete queries from each of the eight SOURCE fitting localities.
No long/unknown/small recording is dropped. All18cost fits and two complete
refits of the first actual producer must finish before selection policy outcomes.
Checkpoints include optimizer, query permutation/counters, RNG, hashes and PID.

## Fixed Decision Controls

Using the same frozen forecaster and predicted moments, evaluate independent
pointwise2%all/easy guards, frame-uniform choice, matched-count frame-joint
budget pooling, and free-count frame-joint budget pooling. Retain every original
recording. The matched joint arm must use exactly the independent count in each
query, not only match an overall rate. If the solver fails or a native numerical
postcheck fails, retain the feasible parent; report solver fallback counts.
Also evaluate the context model with the neural candidate removed, explicitly
an action-bank ablation rather than a retrained representation ablation.

This allocation pools two predicted risk budgets; it does not yet optimize
pairwise collision/composition conflicts or certify physical safety. Those
remain required gaps for the broader paper objective. Do not call this a
completed multi-agent interaction method or deployability proof.

Primary: context-joint-matched minus context-independent paired completion-lower
ADE utility, in percentage points of the fixed SOURCE producer's floor reference.
Unknown disagreement cancels when both policies keep identical forecasts.
Known-mask ADE, paired upper bounds, tails, easy/hard scores, switch counts,
all per-record risk checks and context-minus-row effects are retained secondary
diagnostics. Do not replace the primary with a better free-count or seed result.
The no-intervention floor and raw neural predictor are fixed controls.
