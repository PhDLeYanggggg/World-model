# Pre-Training Reference-Invariance Amendment

No model has been initialized/fitted and no new policy outcome has been read.
Only model-independent data preparation has completed under the first committed
definition. The original registration and Git commit remain retained.

## Structural Correction

The floor reference error and easy-reference mass do not depend on which
candidate amplitude is proposed. The initial decoder allowed its predicted
R/ER to depend on action descriptors. Training equal targets would encourage,
but not enforce, invariance and could create spurious predicted risk budgets.

Before fitting, replace that part with a common reference branch receiving
the same first50 action-invariant history/neighbor fields as the support
branch. The action-cost branch outputs B/H fractions and the EH gate; the
reference branch outputs R/ER. The support branch remains gradient-independent
from the treatment's observed-conditional objective. Both compared arms receive
the identical corrected architecture, initialization and draws. Decoder
coherence, original actions, data, role losses and scientific 2% rules remain.
Nonconstant-weight tests verify exact action-invariant reference/support output.

## Scope Of The Subset Argument

An additional veto of an already-accepted mean/unanimity set cannot create
missing easy reference. This is not a claim that every newly learned veto of
the broader original proposer must fail: the proposer itself has observed easy
reference in all24views. Relearning admission within that proposal set could
already increase support. The proposal-only control therefore remains essential.
Opening all original amplitudes is a separate tested design choice, not a
mathematical necessity proved by that subset argument.

`registration_v2.json` freezes this correction before the real training pilot.
The prepared arrays are reused only after their existing hashes, schemas,
complete scope and known-feature/target parity checks. No evaluation relaxation,
selected threshold, future validity input, new C/H access or claim of success.
