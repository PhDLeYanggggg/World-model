# Fit-Only Stationary Label Resolution Audit

The scene/direction experiment is complete and negative for trajectories. This
audit investigates label meaning, not another threshold search. No primary
metric, target, training population or policy will change. The prospective
native-ADE/FDE primary protocol remains awaiting the user's decision.

Reuse the 365 exactly stationary fit windows from the verified scene-probe cache,
and trace each history/current/future coordinate to the original ETH/Hotel text.
Keep physical-scene grouping and existing agent/run identities. No development,
calibration, confirmation, supplied velocity, destination or group labels.

Questions, fixed before computing the new statistics:

1. Could a constant latent coordinate be consistent with the decimal precision
   of the printed current/future values? Use explicit Decimal rounding intervals,
   not a guessed physical-noise threshold. Display precision is not measurement
   precision or an annotation-error model.
2. Under the supplied H inverse, how far do future labels move in inferred image
   coordinates? Report all-row and changed-row quantiles, return-to-origin cases,
   and nearest-integer pixel residuals of the complete canonical fit recording.
   Inverse-H projection does not establish camera synchronization, matrix-axis
   validity, metric calibration, genuine starts or sensor-as-of annotation.
3. Report fixed maximum-displacement sensitivities at 0.5/1/2/5/10 inferred pixels.
   A 0.001-pixel numerical tolerance handles printed-matrix arithmetic; also report
   how many rows lie within that tolerance of each threshold. This tolerance is
   not an uncertainty certificate. Do not choose a threshold or relabel targets.
4. Report window/agent/stationary-run support, native CV error and its share above
   each cut, so label-count changes are not confused with error-budget changes.
5. Decompose ALL frozen corrected scene-probe predictions into the same fixed
   label-side slices. Retain easy/still rows and errors, including empty slices.
   Do not refit, recalibrate probabilities, select a seed, or alter interventions.
   Slice outcomes are post hoc diagnostics, never new model-selection evidence.

All source/cache/model identities are checked. Raw coordinates and row-level
projection caches stay local; publish only code, hashes, counts and aggregate
metrics. No images, third-party data or model weights in Git. No new neural
training, deployment, formal significance, metric/time claim, Stage5C or SMC.
