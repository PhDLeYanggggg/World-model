# Does training against two causal references improve the forecast?

This is an exposed-development mechanism study, not DroneCrowd calibration or independent confirmation. The preceding motion studies found that getting closer to last-step constant velocity (CV) did not imply improvement over a stronger causal fit to the last four observations (OLS4). I compare two objectives for the same direct 8-observation/12-prediction Torch head, starting from the same fresh initialization at each of three seeds (17, 29, 43). Both arms see exactly the same draws from nine fitting groups (69,746 rows), none of which are in the exposed development roster. They use 900 updates of 128 rows per fit; no early stopping, tuning or arm selection on development outcomes.

- **CV only:** Fit normalized signed ADE regret to CV where any target is observed. For rows with no observed targets, use maximum path disagreement as the conservative debit.
- **Dual reference:** Apply the same construction to both CV and OLS4, and minimize a normalized smooth maximum of the two batch costs (temperature 0.25). Both arms have the same CV positive-harm penalty (0.5 globally, plus 2 on positive-easy rows), the same fitting-only easy cutoff, and the same past RMS normalization.

The primary comparison is dual minus CV-only in conservative completion-lower ADE improvement, with both new paths substituted on the same pre-existing gain-policy recipients, where both paths differ from CV by more than `1e-6`. Otherwise both arms retain the gain-policy path. Freeze forecasts before opening development targets. Compare the two arms to the original gain policy, CV and OLS4, also on the full roster as a secondary result. Normalize percentage-point changes by the known CV ADE mass. Use the existing paired 3,000-source bootstrap, averaging seeds within source. The original 2% easy-risk rule and support requirements are unchanged. Undefined is not a pass. No result from this study can unlock the independent confirmation set or count as deployment evidence.

All geometry is dataset-local. Native observation and prediction steps are not a verified time or metric unit. No latent generation or SMC.
