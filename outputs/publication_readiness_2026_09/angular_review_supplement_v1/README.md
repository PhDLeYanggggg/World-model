# Anonymous supplement v9

The v179 main manuscript is unchanged. The v9 archive retains
the prior evidence and adds six grouped development checks for
direction capacity, fixed recipients, constant-angle capacity,
angle choice, calibration and matched rotation placement.
It recomputes counts and paired intervals from anonymous
location-seed scalars; it does not retrain a model.

The local archive is
`data/stage_cvpr2027_experiments/submission_admin/review_supplement_v9.zip`.
Extract it and run `python3 -I -B -S verify.py` there. The
[receipt](receipt.json) binds the archive to the unchanged
manuscript and the six source readouts. Two builds match byte
for byte, and the isolated standard-library replay agrees
with the grouped reports. Nothing was uploaded.
