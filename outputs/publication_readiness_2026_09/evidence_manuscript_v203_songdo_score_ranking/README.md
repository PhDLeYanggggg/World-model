# v203: explain why the Songdo score abstains

The main paper adds a short diagnosis of the original zero-release
result. The top calibration proposal in all three joint seeds lacks a
selected easy reference. Lower-ranked proposals pass risk, but none can
form an admissible high-score prefix. A same-count comparison on the
already scored confirmation cohort gives no reliable dual-pass ranking
advantage over uniform choice. The original threshold and results stand.
