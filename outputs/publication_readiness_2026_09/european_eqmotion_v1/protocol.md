# Public Fixed-K1 Forecasting On The Current SOURCE Protocol

## Question And Scope

Can the pinned author EqMotion core improve on the original past-context
Transformer under the same EuropeanSquares SOURCE population, causal observation
and request schema, complete loss budget, SOURCE folds and three actual seeds?
This fills a missing public-family control; it is not another critic-width sweep
or a claim that architectural assembly is novel.

Cached_verified: the original European SOURCE arrays, roles, packing, single-fold
designs, preprocessing, baseline choice, nine original PCT checkpoints and
predictions. Fresh_run: nine EqMotion models, a recovery pilot, first full refit,
all SOURCE-excluded inference and exact replay. An exclusion is SOURCE crossfit,
not independent confirmation; SOURCE has previously informed research choices.
The new study does not open development, calibration, confirmation or DroneCrowd
arrays. Historical calibration remains completed and unsuccessful.

## Fixed Public Adaptation

Official source: https://github.com/MediaBrain-SJTU/EqMotion , MIT, commit
`5aec2e0b61c511fa93a24138dd90da59a089084b` with all eight pinned files hash checked.
The original trainer, preprocessing, checkpoints and published results are not
used. The already implemented adapter fixes head 0 before training and executes
only that head. K=1 is deterministic, not best-of-20 evaluation or generative
rollout. Unused heads stay frozen. No family/seed/head is chosen after scoring.

The same eight past ego observations and up to eight complete aligned past
neighbor tracks are available. Both models receive the same causal baseline
rollout and fixed twelve-point request grid. The shared observed-context
max-norm conditioner uses only past values and restores units before loss.
EqMotion uses causal finite differences internally and ignores the baseline
argument in its core; PCT uses it in future queries. The original PCT has a
motion-bounded output wrapper; this EqMotion adaptation emits coordinates.
These are explicit family/parameterization differences, not an isolated test of
equivariance, matched parameters, matched FLOPs or paper-level reproduction.

## Training And Reproduction

Use all original nine single-fold jobs: each fits its four SOURCE localities and
predicts its eight excluded SOURCE localities. Seeds 17/29/43, 4,000 updates,
batch 64, original AdamW and cosine schedule, clip 5, checkpoint 200 and heartbeat
50. Site-normalized available-label ADE, masks, draws and factors are identical
to the original PCT fit. Entirely unknown rows remain sampled without fabricated
labels; future masks are loss/evaluation only. No epochs or thresholds selected
on excluded outcomes. Use the fixed final full-budget checkpoint.

Before full fitting, run actual SOURCE 50->100 versus direct-100 and compare
model, optimizer, sampler, draws, trace and RNG exactly. Profile actual runtime
and memory. The first complete 4,000-update model is separately refit exactly.
Freeze all nine model endpoints and all nine forecasts before any new outcome
reduction. Replay every control forecast from its frozen checkpoint on the same
row IDs. Record initial/output hashes and all input/source identities.
