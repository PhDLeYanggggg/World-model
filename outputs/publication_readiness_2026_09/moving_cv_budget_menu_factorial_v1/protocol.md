# Candidate menus crossed with query budgets

This is a hindsight diagnostic on the same 24 exposed development
recordings, three seeds and nine source groups as the slate study.
It keeps forecasts, the CV fallback, the OLS4 comparison, weighting,
missing-step bounds, and the original recording-level 2% rule fixed.

Cross two factors. The narrow menu is the frozen query slate and the
five geometric prefix rankings. The full bank permits any legal
agent-path action and at most one per agent. Exact counts keep the
frozen slate's edit count in every query. Relaxed counts permit zero
and all legal prefix lengths for the same five narrow generators,
plus the original frozen slate; in the full bank they permit any
number of edits up to the number of agents. Thus the narrow generator
and the full path bank do not change across the count comparison.

Solve the two new intermediate cells and recheck both existing
corners. Independently rescore each incumbent and verify that its
counts and menu membership satisfy the assigned condition. Report
infeasibility, negative solver bounds, unsupported cases and
unresolved cases separately. Report paired source-group bootstrap
intervals for the change in *verified witness rate*. This is not a
confidence interval for the unseen true capacity of unresolved views.

No hindsight decision is an inference feature or a trained policy.
No A labels, DroneCrowd calibration or independent confirmation
outcomes enter this diagnostic. No deployment or threshold change.
