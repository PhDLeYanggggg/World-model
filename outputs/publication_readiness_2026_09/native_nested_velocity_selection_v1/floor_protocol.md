# Fixed decisions under the original CV reference

The primary experiment measures sparse corrections against OLS4. A
separate paired diagnostic retains exactly the same selected rows
and neural paths but changes only the untouched rows' fallback from
OLS4 to CV. This isolates the replacement decisions from the error
of using OLS4 everywhere. It is not a CV-trained selector or a new
deployment rule. Split the selected-action gain into the sum of
observed-step changes and the disagreement debit on missing steps,
with a fixed twelve-step denominator. Compare the matched hindsight
capacity relative to each floor separately. No score, threshold,
edit count, or data role is changed.
