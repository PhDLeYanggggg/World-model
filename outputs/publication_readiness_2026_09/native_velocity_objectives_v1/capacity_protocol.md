# Is there forecast headroom at one edit per query?

Run this supporting diagnostic on the frozen loss-ablation candidates
and the fixed near rule. Use all multi-agent fitting queries where
every arm can make one nonidentity change, and exactly one change
per such query. Compare the full-grid lower gain of a hindsight
choice with a seed-fixed random eligible choice, using the original
CV denominator and the same source bootstrap. An oracle knows
outcomes; it cannot establish selection accuracy, safety or new
independent evidence. No candidate, threshold or budget is selected
by this readout.
