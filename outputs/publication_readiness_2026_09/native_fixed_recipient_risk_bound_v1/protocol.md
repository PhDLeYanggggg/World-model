# Can Any Reranking Repair Risk At The Same Recipients?

This post hoc diagnostic uses the frozen motion recipients,
CV-difference neural counts, and the exact same bank as the
visibility study on the exposed development roster. It reads
released labels only to calculate an optimistic lower bound,
not to choose an inference action.

For each recording and seed, minimize each of the original
all-harm excess, easy-harm excess and signed easy excess
separately. For a query with k fixed neural replacements, take
the k smallest increments over its selected motion paths,
where each row's increment uses its minimum-cost legal neural
path. Also calculate a relaxation with arbitrary neural counts
but the same recipients. Selected reference masses do not change
with a genuine replacement. A missing reference or a strictly
positive component minimum proves infeasibility for that slate.
Passing separate component tests does not prove joint feasibility.

Check all 102 recording-seed views, the unchanged 2% rule and
pixel-space 8/12 setting. Use numerical tolerance only for the
infeasibility claim, never to relax the original score. Publish
only aggregate reasons, not label-aware choices. No training,
external access, new risk definition, deployment, Stage5C or SMC.
