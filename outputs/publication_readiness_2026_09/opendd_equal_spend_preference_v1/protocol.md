# OpenDD: learn preferences between equal-spend recording plans

Use the frozen OpenDD 8/12-step development cohort, seven outer location
holds and seeds 17, 29, 43. Keep the forecast paths, nested nominees,
chronological credits and original risk and utility definitions. The six
donor locations provide all fitting outcomes. Each donor's ranker and
easy cutoff come from the five locations excluding the donor and the hold.

Construct pairs within a donor recording. Set the count and movement cap
from either of two label-blind causal token schedules: spend one when
affordable, or use fixed random query priorities. Find a positive plan
using the label-aware solver; verify it with the original scorer. Contrast
it against the anchor, a minimum-movement plan, and a fixed random-priority
plan that fail at the same count and cap. Deduplicate equal pairs. Do not
turn unavailable or unresolved witnesses into positive examples.

Fit identical additive count heads for 500 updates on the same pairs.
The primary head predicts relative preference; the control classifies
each plan's pass label independently. Both sum query score increments
over zero edits, divided by the square root of the edit count at fitting.
At evaluation, reuse the frozen online counts and movement caps and
maximize each head's additive score without outcomes. Report pass-rate
and conservative gain differences against the archived frozen-score
allocator, at equal site weight, with 3,000 location bootstrap draws.
Unresolved allocations retain the identical archived plan and are counted.
Because the allocator can see the whole score sequence and final counts,
this is not a streaming policy or external confirmation. No threshold
search, new split, release, or external outcome access.
