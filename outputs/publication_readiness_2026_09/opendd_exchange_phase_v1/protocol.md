# OpenDD: change when an edited path departs, not where it ends

Start with the same frozen 780 edits and all 7,198 legal one-edit
exchanges over 606 views. Modify only the incoming recipient's
forecast residual relative to CV. Interpolate its earlier or later
values inside the two intervals bounded by the forecast start, the
original peak residual, and the end. Retain the peak step exactly.
This keeps recipient, edit count, per-recipient maximum displacement
and forecast endpoint fixed, so per-forecast endpoint error cannot
change. The two phase shifts have fixed square-root and square
exponents. No positions from the future targets enter the proposals.

First report the full exact oracle frontier by original, early, late
and expanded menu, including the previous protected-endpoint deletion
test. Report the positive frontier and utility floors of 0.10 and
0.50 percentage points; they do not change the original risk rule.
Then keep the frozen ranker's action and 101-view intervention mask
exactly fixed. Compare original, early, late, uniform phase and the
shape closest to the past-derived OLS4 forecast over the first three
steps. The uniform expectation is exact. Evaluate paired conservative
utility and risk-and-utility pass counts, with location bootstrap
after averaging seeds. No training, external target access, new
calibration, or deployment.
