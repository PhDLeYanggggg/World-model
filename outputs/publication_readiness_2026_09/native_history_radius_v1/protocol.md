# A Past-Backtest Radius For Near-Baseline Actions

The original full bank cannot supply an easy action on one recording
under the original 2% rule. Test whether creating different forecasts,
rather than reordering those same forecasts, restores support and
retains accuracy. Estimate the 20th percentile of normalized observed
CV error among easy rows on thirteen fitting sources, withholding the
entire scored source. Compare a pooled fit to a fit stratified by
CV backtest error using only steps inside the eight observed positions.
The latter uses four fixed buckets and falls back to the pooled
value for insufficient fitting-source support. A 20th-percentile
fit is an empirical estimate, not a guaranteed lower bound.

Clip each candidate's largest path displacement from CV to 2% of
that estimate, restoring image-pixel scale. If the candidate is
indeed easy and the estimate is below its true observed reference,
the reverse triangle inequality makes this radius sufficient for its
per-row harm ratio. Neither condition is known at inference. Missing
labels and unsupported references still receive the original scoring.

For the actual policy keep the exact same screen-first 2,194 switches,
agents and query mask from the verified portfolio. Compare the
unclipped paths, pooled cap, history-conditioned cap and a material
history cap that keeps the original path if the cap is below 0.25
pixels. The 0.25 value is an explicit sensitivity floor, not a claim
of annotation resolution. Primary paired utility is material vs.
original. Also check held selected-easy empirical coverage.

For the separate label-aware capacity check, add all changed clipped
paths to the original full bank. Compare literal changes with the
subset whose displacement from CV is at least 0.25 pixels. Keep the
same recipient roster and original per-query caps; recheck 2% risk
feasibility and conservative OLS4 capacity with missing-outcome charges.
Report unresolved solves, never promote hindsight actions. No new
threshold tuning, external data, deployment, Stage5C or SMC. Same
8 observed / 12 predicted annotation steps in native pixels, three
forecaster seeds, and 34 exposed recordings in 14 source groups.
