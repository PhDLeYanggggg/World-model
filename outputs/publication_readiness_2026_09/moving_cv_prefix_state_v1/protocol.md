# Predict marginal risk given a causal recording prefix

Keep the v141 analytic bank, exact query option menus, 8/12 steps,
CV reference, OLS4 comparator, original risk checks, and nine
development source groups with three seeds. Leave A and the
independent confirmation role closed.

For each chronologically ordered query, summarize only previously
issued forecasts: predicted dual gains, all/easy excesses, signed
easy margin, selected easy support, and total reference masses.
The primary state follows a fixed causal shape portfolio, with no
access to the actual outcomes of earlier forecasts. Training labels
measure how the current query changes the positive excess of this
prefix, using fitting-only outcomes to score the hypothetical
choice. Compare identical models with the causal state present or
masked; both predict the same dual gain, marginal risk, and pair
geometry targets, with the same draws and optimization.

Primary comparison: state and masked models choose among exactly
the same current options at the original portfolio's exact query
counts. Compare with a matched independent selector. Secondary:
update the state using the model's own earlier actions (closed
loop), both at matched and free counts. Calibrate risk price and
abstention margin only in the assigned calibration role under the
original checks. Report 3,000 paired source resamples, support,
signed easy change, counts, pair geometry and both comparators.

The state is reset at every recording. No future outcomes, future
query histories, final recording length or teacher decisions enter
inference. A zero-intervention fallback does not pass undefined
easy support.
