# v205: check the release result at equal movement

The main paper adds a movement-matched sensitivity check to the
fixed-proposal OpenDD experiment. After matching the intervention count
and both movement budgets, the observed-label gain is positive but the
conservative contrast remains negative. Matching movement is not the
same as matching the label coverage of that movement. The original
policy and independent external results are unchanged.
