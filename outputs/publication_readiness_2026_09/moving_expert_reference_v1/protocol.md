# Frozen-Expert Context For Action-Invariant Reference Learning

## Question

The preceding role-separated model improves matched trajectory utility but
passes only23/72 original recording-risk views. Selected easy reference is
overpredicted in61/72 views. Making reference inputs action-invariant removed
candidate rollout descriptors, including potentially useful frozen-expert intent
signals. Does sharing those causal descriptors per agent improve reference
learning and full-policy decisions, without changing harm or support learning?

This is not another direct upper-quantile, generic selected-query, denominator
subsidy or marginal coherence projection experiment. Those earlier negatives
remain. It is a specific missing-input hypothesis, not a new safety definition
or a novelty claim for adding a context branch.

## Matched Intervention

Use the final role-separated checkpoints as immutable parents. Freeze their
conditional harm/easy-harm, benefit proposal and label-support outputs. For each
agent, locate the original full-amplitude action6 in the existing causal bank.
Its last70 raw rollout/neighbor descriptors form shared expert context. The
first50 history/neighbor descriptors must match every action exactly. Context
construction takes only raw causal features and row/action IDs, never labels,
future validity or target endpoints. No new predictor or forecast is trained.

Both new arms have the same reference network: inherited history50->32 plus
an additive context70->32 projection, SiLU, then32->2 logits. The new context
projection starts at zero; the inherited reference state and all other initial
parameters match exactly. History-refit masks only the new context input to zero;
expert-context admits it. Both refit the reference network for4096updates, using
the same initialization, full source/query sampling draws, known-only loss and
fitting normalization. The conditional target is R and ER with the old known-only
RMS, not raw FDE or an unobserved-label imputation. The context normalization is
also known-fitting-only, excluding the entire query source.

Both outputs obey0<=ER<=R. New benefit is min(frozen benefit,new R), preserving
coherence; frozen H/EH and support probability remain bitwise unchanged. Thus
reference learning can alter utility through the required benefit cap as well
as the constraint denominator. Report this, rather than claim a pure risk-only
effect. The inherited R/ER gradient previously also included the benefit-cap
term; both new arms replace that with reference-only supervision. Only the
comparison between the two new arms isolates shared context information.

References are predicted once per agent and broadcast across its legal actions.
They are not a different denominator for each candidate. The conditional risk
and support networks are not trained or replaced. Softplus/sigmoid outputs are
predictions, not conservative confidence bounds or calibrated probabilities of
physical safety. A lower average MSE is not a selected-risk guarantee.
