# Cross-Source Causal History Retrieval

## Question

The completed shared-versus-separate risk-head experiment fails the fixed
decision screen. Test whether source-excluded local causal analogues carry
usable risk information that the fitted forests miss. This is an information
and nonparametric risk-model comparison, not a new neural trajectory model.
It is not an independent confirmation or a claim that nearest-neighbor learning
is novel. Earlier European query-level analogue experiments remain negative;
the present unit is the frozen Moving native8/12 proposed agent action.

## Fixed Data And Exclusions

Use the same 48,061 known own-B proposals across eight source-held folds and
three already-exposed contexts. Keep the 1,274 unknown-proposal count explicit;
do not invent labels. No new C/H or reserved Moving20, DUT or DroneCrowd readout.
Original24-group primary remains NA, not passed. Original 2% positive-harm,
easy-net, reference/support and empty-control rules remain. No identity waiver.

Rebuild only recording/agent/frame metadata from the frozen admitted source
packer. Check source membership and global row IDs against the verified fitting
cache. Exclude the entire query source component from the donor bank, learned
normalization and supervised fitting. Thus a query's own recording, track and
overlapping windows cannot serve as references. Raw IDs are not model features.

Use at most one donor from each (source component, local agent ID) bucket.
This conservatively merges repeated local IDs across linked recordings. It
may merge different people, and relabeled duplicates may remain; it does not
certify distinct physical people or independent samples. Report bucket and
recording counts, and how much overlap the bucket constraint removes.

## Models And Null Control

Original120 causal features, source/query weights and two signed budget-excess
targets stay unchanged. Means/std and target RMS use donor sources only, as in
the existing forest control. Clip standardized features to [-8,8]. Compute
Euclidean distances divided by sqrt(120), using exact SciPy pairwise distance.
For each identity bucket choose its nearest window, then take the nearest32
buckets. Resolve ties by sorted bucket key then global row ID. Use the original
fitting weights, renormalized across selected references, to average targets.

- track32: primary identity-distinct nearest-history risk regression.
- prior: constant donor-weighted target mean, using no query geometry.
- misaligned32: deterministic within-source permutation of query-to-reference
  associations, with no query labels. It preserves the unweighted prediction
  multiset, not every query-weighted moment. One null draw is not a formal test.
- shared64: original cached, hash-verified forest control.

No k, feature, distance, threshold, source or seed search. A bank with fewer
than32 buckets is not estimable, not declared safe. Metadata preparation reports
this before any predictions. Predictions receive query features/source only;
future outcomes enter scoring afterward, never donor selection for a query.

## Readout

All folds remain. Report normalized risk MSE, original joint decision cost,
false-safe and false-reject cost/counts, selected known reference/harm mass,
source coverage, effective donor-weight count, disagreement and fixed distance
slices [0,.25,.5,1,2,4,infinity). Distance is standardized feature space, not
metres or calibrated semantic similarity. Label disagreement does not prove
irreducible uncertainty. Easy occurrence and partial future labels remain weak.

The internal screen keeps >=1% cost reduction versus shared64 with no increased
harmful-admission cost, and additionally requires lower cost than prior and
misaligned controls in >=2/3 contexts. This is not a replacement scientific
gate: passing it would not establish original scene-level risk/support safety.
Do not equate zero selected rows with identity certification.
