## Scope of the positive finding

The current experiment supports decision-coupling utility on this exposed
fitting cohort. It does not demonstrate a new neural dynamics producer,pairwise
interaction learning, superiority over a reoptimized physical-only allocator,
independent scene generalization or safe deployment. Query targets may omit
visible context agents. The geometry summary is a predicted-path proxy,not
ground-truth interaction safety.

The follow-up deletes only actual neural uses while freezing other actions.
That is a meaningful use ablation,but not the same as reoptimizing the entire
physical-only bank. The stronger comparator should use the same cost estimates
and the physical independent rule's query count as a feasible common anchor.
