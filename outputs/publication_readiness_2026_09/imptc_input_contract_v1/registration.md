# Input-Only Unit Contract Diagnostic

Registered before this diagnostic is run. The question is whether changing only
the numerical coordinate unit changes frozen forecast or risk-head behavior.
This is not a forecasting evaluation, model-selection exercise or calibration.
No outcome-based threshold, coordinate factor or checkpoint will be selected.

Use all four verified IMPTC sample recordings. Query frames satisfy index modulo
181 equals 7. Include targets with eight observed consecutive master indices;
retain partial-history agents as masked context. No class, tracker status,
whole-track length, future support or endpoint is an inference feature/filter.
Use native master-index stride1 and twelve requested indices, not SDD stride12
or an assertion of matched seconds. There is no resampling/interpolation.

Unit multipliers are fixed at .01, 1 and 100. The frozen Transformer and EqMotion
are the coupa-excluded seed17 native-coordinate source fits, chosen by fixed
view rather than performance. These are two engineering probes, not a new
ensemble or deployment choice. Compare normalized predictions on the *same
past* under the three units; never compare to future coordinates. Also compare
the corresponding three frozen risk heads, including simple damping. A changed
net-gain sign is not a complete deployed scene-policy decision.

Verify every file in the current guarded producer identity by hash, all twelve
native-coordinate Transformer fits, twelve EqMotion fits, and thirty-six net
moment head receipts/checkpoints. Check source-site and row identities against
the SDD manifest. This bounds local producer lineage, not remote project history
or scientific independence from every related VRU/DeCoInt source.

The proposed input repair is a new version, not a modification of the frozen
model: shared past-prefix extent defines a reversible dimensionless scene unit;
the existing target-relative encoder then runs in that unit. Nearest-neighbor
sort keys use nine-decimal canonical-distance buckets then agent ID, stabilizing
floating-point ties without quantizing coordinates. This precision is
dimensionless. Zero-extent scenes
are unsupported for learned inference. The new cost schema omits native scale
and uses normalized forecast disagreement. It is deliberately incompatible with
the existing 356-column cost-head checkpoint and requires source-only refitting.
The repair will be tested for scaling/translation equivalence, prefix mutation
invariance, malformed-input rejection and exact same-version replay.

No external outcome is opened. IMPTC covariates become engineering-design-exposed
under this named scope; they are not untouched confirmation inputs. Upstream
IMM processing causality remains unverified and the sample has one physical
intersection. DroneCrowd outcomes and inputs are not accessed. The SDD primary
protocol, frozen deployment, Stage5C and SMC do not change. Numeric equivalence
is not model lift, calibrated safety, metric validation or submission readiness.
