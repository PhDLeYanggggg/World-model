# Source Discovery, Not Experimental Admission

This is the discovery-time record. The completed acquisition, structural
counts and split interpretation are in [conclusions.md](conclusions.md).

The author's [project page](https://github.com/fyw1999/MovingDroneCrowd) links
the current [dataset repository](https://huggingface.co/datasets/fyw1999/MovingDroneCrowd).
The latter declares CC-BY-NC4.0 and currently distributes the extended
MovingDroneCrowd++ archive. Its original-conference subset is separate from
the extension; neither is Wen etal.'s2021 DroneCrowd release.

The original [ICCV2025 paper](https://openaccess.thecvf.com/content/ICCV2025/papers/Fan_Video_Individual_Counting_for_Moving_Drones_ICCV_2025_paper.pdf)
describes head/identity annotations and moving-drone imagery for counting.
That publication is a source lead, not evidence that this collection supports
M3W's8/12 forecasting task or safe neural intervention. This discovery read
covers project/dataset pages and the original paper's dataset/method sections,
not an exhaustive literature review or validation of the extension's results.

The public metadata API returns the pinned revision and archive size recorded
in the config. The published LFS digest is expected provenance; selected ZIP
members will be checked, but the full archive is not yet downloaded/hashed.
License declaration does not independently settle underlying video rights.
No code/weight is run and no raw data is redistributed.

Preserve all112 existing DroneCrowd confirmation reservations and DUT's roles.
The suggestion to allocate training clips from that protected source is not
implemented. New data stays diagnostic-only until actual source geometry,
history support, scene overlap and admission are resolved. No predictive
outcome, independent-site, metric/time, deployment or readiness claim follows.
