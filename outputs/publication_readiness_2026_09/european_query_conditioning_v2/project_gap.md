moment does not reliably improve. Nor should more mean-pooling capacity be
declared the solution: the same cohort's easy squared risk error got worse.

optimizing the soft action objective. Before any new fit, reconcile the existing
unprojected-cost, hurdle, fixed-floor, selected-weighting and decoder controls
so this is not a renamed retry. Use the same causal features, frozen benefit
and reference estimates, matched source/query draws and budget. Make the new
comparison earn its cost through better known fitting signed-risk prediction
on fixed cohorts, without hiding unknown outcomes or moving the2% criterion.
If it fails even there, do not spend another held readout on it.

This next repair is **not_run** and not yet a frozen training protocol. It is
not an assertion that an unconstrained residual, new loss or more epochs will
work. If a distinct matched test is not justified, redirect development to
stronger forecast controls and the causal observability gap, not independent
confirmation or a fabricated new stage success.
