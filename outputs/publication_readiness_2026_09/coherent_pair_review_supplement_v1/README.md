# Shared-position audit: anonymous review replay

The v21 supplement accompanies the unchanged
[v190 manuscript](../evidence_manuscript_v190_external_bounds/README.md).
It embeds the previous archive byte for byte. The added panel reproduces
the OpenDD shared-position endpoint estimates and seven-location
bootstrap intervals, verifies the original bound against the inherited
panel, and records the checked aggregate witness counts. No forecast
weights, trajectory coordinates or witness positions are included.

Extract the local archive and run `python3 -I -B -S verify.py` from the
extracted directory. The [receipt](receipt.json) binds the archive,
the manuscript and the development readout. This replay does not
recompute neural inference or reconstruct individual completions.
Nothing was uploaded to OpenReview.
