# Fixed-budget easy-support reranking

The OpenDD disagreement analysis identifies missing easy reference as a
frequent loss of qualification. Test whether a separate, already trained
actor support predictor improves the same two-edit decisions. Keep the
original seven development locations, 8/12 grid, query, paths, edit
radius, three seeds and 126 held/calibration directions. There is no
new training, dataset split, threshold tolerance or outcome source.

Replay the archived additive, same-family and joint decisions. On the
same candidates, subtract 0.25 times the negative log of the larger
actor support probability from each archived merit. This uses the same
fixed weight as each existing risk penalty. The larger marginal is a
ranking proxy, not an independent-joint probability or certificate.
The support head sees eight past steps and prefix backtests only. Bind
the same donor easy cutoff and five training locations for both heads.
As a negative control, apply the same penalty to the additive merit
after permuting support logits within each observed query. The shuffle
is deterministic from 3227, training seed and location index.

Primary comparison: additive plus support versus additive. Report
paired conservative trajectory utility and count of passes on the
original checks plus both CV and OLS4. A support improvement alone is
not a utility win. Compare the permuted control, same-family and joint
variants without choosing a new weight on held outcomes. Also report
observed-step and conservative relative-motion contrasts and easy
denominator coverage. Use the original same-denominator paired
contrasts and 3,000 paired location bootstrap draws. Treat all results
as exposed development, not independent confirmation.

Separately set each release threshold on the opposite excluded
location with the original tie-complete dual-passing prefix. Freeze
choices and thresholds before held scoring. Released counts may differ;
empty releases or absent denominators do not certify the policy.
No external outcome coordinates, manuscript edits or deployment changes.
