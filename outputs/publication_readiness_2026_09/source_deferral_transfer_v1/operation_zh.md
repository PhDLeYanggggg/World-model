# 固定成本回退模型：本轮结果与复现

## 这次做了什么

这轮没有新增训练，也不是训练卡住后换成 NumPy。上一轮六个真实 Torch
模型已经完成训练；本轮冻结全部终点，在未参与这些模型拟合、但以前已经
探索过的 bookstore 场景上做一次固定评估。三份旧神经基线先校验，再精确重放。
没有挑种子、挑 checkpoint 或根据评估结果改阈值。

评估包括 6,944 个窗口、7 段录像、181 个录像内 agent，只有 1 个物理场景。
不能把窗口或录像数量包装成大量独立场景。主任务的独立校准和最终确认数据
仍未打开。本轮使用源数据的 8 步观察、12 步预测，间隔 12 个原始标注帧；
它不是经过时间换算的跨数据集统一秒级任务。

## 结果怎么理解

| 方法 | 相对静止历史下 CV 基线的改善 |
| --- | ---: |
| 原无保护神经预测 | -1.7438% |
| 成本监督神经预测，不加回退 | -1.7479% |
| 成本监督神经预测，加固定回退 | -1.2456% |
| 普通期望成本模型，加固定回退 | 0%，全部退回基线 |

负号表示更差。成本监督的回退比无保护神经预测少犯错，但仍然不如运动基线，
三个种子都失败。其相对 CV 的条件录像 bootstrap 区间是
[-4.4301%, -0.5669%]。这不是独立场景确认区间。

因此，“相对坏的神经对照改善 0.4983 个百分点”和“模型有正迁移”不是一回事。
预测器本身没有变强。全回退的 0% 也不是新模型成功，不能部署升级。

简单样本上 CV 误差为零，百分比退化不能计算。成本监督回退后的平均额外误差
仍为 0.01581748 个标注像素，不能写成 easy <=2% 已通过。

## 失败原因已经知道多少

确定的事实：训练集小收益没有迁移；候选未来轨迹弱；回退不足以消除简单样本伤害。
按录像等权、按 agent 等权后仍为负，不只是窗口数量不均衡。

额外检查了 15,430 个训练输入，其中 153 个属于完全重复输入组，只有 38 个
存在同输入不同未来标签。因此，目前不支持把大规模精确输入冲突当作主因。
但这不能证明特征已经足够，也不能排除近似输入歧义。

待检验的解释是：风险头训练时看到的是模型对自己训练数据的误差，可能过于乐观；
也可能存在预测器与回退头联合训练时的目标漂移。两者尚未被实验分离。

下一项工作应先在训练场景内部生成真正的场景外预测和 gain/harm 标签。
每个内层留出场景的标签都不能被对应模型、父 checkpoint 或预处理见过。
先检查候选轨迹有没有真实增益，再训练风险头。不能继续调整 bookstore 阈值。
这个后续实验尚未运行。

## 如何复现本轮

在项目根目录使用原生 arm64 环境：

```bash
.venv-pytorch/bin/python scripts/run_m3w_source_deferral_transfer.py --registration configs/m3w_source_deferral_transfer_v1.json --audit-only
.venv-pytorch/bin/python scripts/run_m3w_source_deferral_transfer.py --registration configs/m3w_source_deferral_transfer_v1.json --replay
.venv-pytorch/bin/python scripts/verify_m3w_source_deferral_transfer.py --registration configs/m3w_source_deferral_transfer_v1.json
```

完整命令和哈希见 [复现记录](reproducibility.md)。九份模型输出精确重放；重复
评估前后 313 个文件不变；22 项相关测试通过。没有重跑完整历史测试套件。
输入检查曾因 NumPy 计数不能写入 JSON 失败，已经补回归测试并修复；失败日志
保留，重跑指纹一致，前面的评估不受影响。不能把第一次失败隐去。

代码、聚合报告和原创结果图可以提交；原始数据、逐行结果、缓存、图像和模型
权重不提交。当前没有本轮后台进程，不存在把运行中任务写成已完成。

结论仍是：没有新增可部署模型，没有达到投稿准备完成。旧 Stage37 指标仍受

foundation world model，不作米、秒、人工 gold 或物理安全声明。
