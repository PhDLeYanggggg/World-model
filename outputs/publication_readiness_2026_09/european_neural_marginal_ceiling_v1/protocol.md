# Does The Frozen Neural Path Add Opportunity?

This is a new post-hoc SOURCE-development diagnostic after the negative
complete-region trial,not a preregistered primary result or independent test.
The previous held-support feasibility check established a positive feasible
physical/mixed oracle in all62record/context views;it did not quantify the
marginal neural utility above the best physical candidate per query. The old
bookstore candidate-ceiling experiment is a different cohort/task.

Use the same sixfixed frozen-forecaster contexts and all48source/scope groups
without repeating controller seeds. Compare per-known-query minimum ADE among
the causal floor plus sixlegal physical candidates with the minimum after
including the legal frozen neural path. Report all/hard known-ADE gains,
neural marginal gain,availability/strict-win counts and scale-normalized gain
quantiles,with per-record/source results and conditional3,000-locality intervals.
Use the original fitting-defined hard label. Validate evaluation support
against the completed primary aggregates.

These oracles explicitly use future labels for diagnosis only. No oracle
choice,label,endpoint or new feature store is exported for inference. This is
an empirical ceiling for one fixed per-query saved-path candidate class on
known ADE support,not a ceiling for a retrained predictor,blends,unobserved
full paths or scene-joint physical validity. Unknown outcomes remain unknown.
Zero reference mass is not_estimable,not a measured improvement or safety pass.

The diagnostic can distinguish limited available neural opportunity from an
unsolved causal routing problem;large oracle opportunity is not evidence that
a causal selector can recover it. Do not promote it as learned performance.
