# Paper Evidence Note

## Permissible Result

In a controlled source-development study with 144 matched risk heads, a
positive-disagreement fractional-harm auxiliary improved conditional harm-event
ranking in five of six full-forecast source assignments. It did not improve
conditional easy-harm MSE consistently: no primary interval was positive,
one was negative and five overlapped zero. The failed prespecified gate kept
the deployment policy unchanged. This supports the distinction between harm
ranking and transferable harm magnitude, not a new safety guarantee.

Use the full paired table and locality-bootstrap intervals. Three-seed means
were resampled across four held localities per source assignment. The 144 heads
are not 144 independent scenes, and the source assignments overlap. These
outcomes are development-exposed, not a held-out paper confirmation set.

## Claims Not Supported

No ADE improvement, new world-dynamics contribution, calibrated harmful-event
probability, selective-risk guarantee or generalizable deployment benefit was
measured in this round. Fractional Bernoulli loss is not claimed as novel.
The current result does not justify opening the independent confirmation set
or declaring the project submission-ready. No metric/seconds, true3D,
foundation, human-gold or physical-safety statement is supported.

The registered source provides limited proper-scoring-rule background. It is
not evidence for the empirical repair or a theorem about locality shift.
Stage5C and SMC remain off. Preserve the negative primary endpoint alongside
the positive secondary ranking evidence in any eventual paper.
