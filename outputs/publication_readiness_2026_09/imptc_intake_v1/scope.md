# IMPTC Source Intake Scope

Registered before acquisition and before any forecast readout, 2026-09-24.

The immediate task is a source conversion and support audit, not a new model
experiment. Acquire only the publisher's `imptc_samples.tar.gz` from Zenodo
14811016 (347,692,691 bytes; MD5 d2bf9579b127b74927150bd3666a034f). Retain the
archive privately and inspect bounded JSON annotations without extracting or
viewing bundled media. Do not execute publisher code. The dataset license in
the Zenodo API is CC-BY-NC-4.0; the repository's Apache code license does not
replace it. Attribute Hetzel et al., IMPTC, IV 2023, DOI
[10.1109/IV55152.2023.10186776](https://doi.org/10.1109/IV55152.2023.10186776).

No previous IMPTC/record-ID/Aschaffenburg match was found in the scoped local
configs, research state, output reports or prior data manifests. This is an
exposure search, not proof about inaccessible remote assets. CREATE's latest
saved read-only refresh failed authentication; remote contents remain unknown.

All sequences belong to one physical intersection. Sequences, tracks, time
windows, traffic-light groups and cameras must not be counted as independent
physical sites. No train/calibration/confirmation split is assigned here.
DroneCrowd remains reserved and closed. Do not open model errors, fit a model,
build goals, tune thresholds or use the samples as confirmation.

The audit will count every released track, timestamp join, duplicate, gap and
past-eligible history. Record structural support for K=8/16/32/64 and complete,
partial and absent future12 labels at source-master strides 1 and 10. Stride10
is a source-support diagnostic only, not an authorized replacement of SDD
stride12 or a claim of matched physical prediction duration. Eligibility uses
only the past; future support never filters a query from the population.

Only coordinates at or before the query enter a past-reader. Derive velocity
with backward differences; do not import published velocity, full-track class,
length, start/end times or future availability into inference. Keep class and
status provenance separate until their temporal production is established.
Producer-side filtering, interpolation and coordinate calibration must be
audited separately from local past indexing. Report publisher units as such;
do not infer metric, seconds-level, true3D or foundation validity for M3W.

  `outputs/reports/stage5_data/conversion_report_tgsim.json` already records

  prediction errors, and Stage18 lists it in JEPA data. Its existing archive
  README says CC-BY-SA-4.0, not the DLR web illustration's different license.
  Neither downloading again nor changing the horizon restores independence.

unmatched local source. No forecast-based source selection has been performed.
