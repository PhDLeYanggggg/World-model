## Supported Findings

1. **An estimator-only replacement is insufficient.** The fixed forest has no
   source-validation MSE superiority over the selected neural checkpoint:
   difference+0.021061, nominal interval crossing zero.44/72 individual wins do
   not outweigh locality-balanced magnitudes. This is not evidence that all
   neural fitting is optimal or that the causal features are irreducibly weak.
2. **Global loss and useful switching remain misaligned.** The transferred mean
   signed-score error is lower, but its interval crosses zero, and matched-count
   ADE is worse by0.148667%. All three seed means and11/12 locality means lose.
   Lower overall regression loss is not a reliable proxy for useful selection.
3. **Preservation improves, but strict selected-tail safety still fails.** Whole
   easy ADE degradation falls sharply relative to the unconstrained neural arm.
   The screened forest's worst whole-easy degradation is0.032322%, yet selected
   easy harm reaches7.550605% and fails6/68 defined directions. The denominators
   describe different questions; one cannot substitute for the other.
4. **A source screen does not calibrate another locality.**28 source models pass
   the fixed completion screen. Four transferred all-risk and six easy-risk
   views fail;148 others have undefined risk.1,953 unknown selected occurrences
   remain explicitly reported. Missingness was not added to inference eligibility.
5. **A seed interaction deserves a crossed control.** All six screened easy
   failures appear with seed43. That shared seed affects upstream forecasts,
   controller assets and this cost regressor. The present experiment cannot
   separate those causes; dropping seed43 would be post-hoc selection.

## What Remains Unidentified

- Whether failure is primarily upstream forecast/controller seed sensitivity,
  cost-head variance, label noise, missing causal information, or target design.
- Whether a different regularization budget improves small-source fitting. This
  fixed conventional comparator is not an exhaustive forest tuning study.
- Whether unseen independent data support utility or the2% selected-reference
  risk requirement. No independent roles were opened for this control.
- Whether a joint query decision mechanism can capture benefit without these
  selected tails. Nothing here establishes a neural dynamics contribution.

## Next Narrow Action

Register a **crossed cost-head seed control** before fitting. Hold the seed43
producer/controller predictions, causal features, native targets and original
source optimization/validation partitions fixed. Train the same128-tree cost
head with estimator seeds17 and29, retaining the existing43 results as the third
arm. Keep all seeds, no transfer-based winner, no threshold sweep and no changed
2% budget. Freeze new source screens/actions before exposed-development readout.

Compare source-validation calibration and the same transferred directions under
this one-factor change. This tests head stochasticity versus a fixed upstream
problem more directly than training another architecture. If failures persist
across head seeds, inspect predicted versus realized benefit/harm/reference
components for the frozen failures and source analogues before changing the
loss. If variance dominates, compare a predeclared average policy, not a best
test seed. This next experiment is **not_run** in the present evidence packet.
