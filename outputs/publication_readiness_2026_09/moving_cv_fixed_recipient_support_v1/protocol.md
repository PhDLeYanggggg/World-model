# Support for fixed-recipient changes at equal peak displacement

Use the frozen 54,748-edit parent on the same exposed development
roster and native 8/12 protocol. Keep its recipients exactly and
reduce each path to a fraction of the parent peak. Competing
directions are scaled down, never up, to the same peak. Uniform
shrinkage is an explicit same-recipient, same-peak reference.

Train a pooled action comparison model and one model per training
source using only analytic paths and causal motion features. Random
analytic anchors avoid using a training recording's outcome-fitted
recipient policy as a feature. Train on observed benefit, paired
missing disagreement, CV/OLS4 conservative gain increments, risk
increments and annotation support. The source-consensus arm permits
a direction change only if every source predicts positive conservative
benefit, no increase in the three risk terms, and adequate expected
annotation support. This is a learned screen, not a risk guarantee.

At half peak displacement compare uniform, pooled and consensus on
held development sources. Use calibration roles only to select among
those families at quarter, half and three-quarter peaks, requiring
the unchanged original recording rule and positive conservative
gain over both CV and OLS4. Otherwise return CV. Report grouped
uncertainty and paired neighbor geometry. Compare with a hindsight
upper bound ignoring risk but keeping recipients and peak fixed.
Do not open A or any independent confirmation outcomes.
