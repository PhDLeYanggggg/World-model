# Convex Amplitude Cost Head: Model And Data Card

## Scope And Outcome

Experimental learned forecast-admission costs on fit-admitted MovingDroneCrowd++
sources. No new trajectory backbone, JEPA, Transformer, ordinary residual,
latent rollout, correction specialist or stochastic generator is trained.
This head is not deployed and does not make M3W submission-ready, true3D or
a foundation world model. It is a component study inside a 2.5D scaffold;
the measured trajectories are 2D image-plane paths.

The fixed joint-free paired completion-lower comparison is -1.830778 pp
[-3.623868,-0.422953]; known-label difference is -0.021859 pp
[-0.529905,+0.505792]. Only 10/348 repeated recording views meet the original
full risk contract. See the complete policy table and failure analysis rather
than interpreting the shared ~11.7% floor-relative gain as a new contribution.

## Architecture And Inputs

- 18 fresh constrained heads across three actual seeds 17/29/43 and the
  original producer/critic/held orientations. Eighteen unconstrained controls
  are cached_verified, not newly trained; both arms are freshly inferred.
- 28,229 parameters, width64, same raw initial state as each matched control.
- 428 causal fields: past trajectory/geometry and candidate/physical baseline
  diagnostics, with the same 48 shared-motion fields zeroed. No admitted RGB,
  scene raster or goal-learning input in this comparison.
- Candidate paths are floor+alpha*(frozen neural-floor), using the same
  seven alpha values 0,1/32,1/16,1/8,1/4,1/2,1.
- Outputs: expected benefit, positive harm, shared reference error, shared
  easy reference error and easy harm. No future trajectory is directly
  generated by the cost head.
- Nonnegative normalized hinge mixtures impose convex H/EH/non-easy curves.
  Shared reference moments and original CV-defined easy event are unchanged.
  Benefit is clipped to the reference and remaining causal discrepancy.
- Original FP32 encoder/softmax/loss; stable float64 linear hinge arithmetic
  and hinge inference are disclosed, not a separate precision ablation.

Convexity does not establish cost calibration or realized risk. The finite
network/optimizer need not recover the true conditional mean. Query-context
membership is the declared eligible target roster, not a claim to predict
every person visible in an image. Scene joint allocation shares predicted
budgets and does not optimize physical collision constraints.

## Data, Roles And Labels

The unchanged 64-recording fit admission contains 195,286 past-eligible native
8-observation/12-prediction windows. Only 58 recordings in 23 source groups
support the task. The original 24-group primary remains not estimable. These
are overlapping windows/source contexts, not independent sample counts or
verified independent geographic sites. Dataset-provided annotations are not
newly independently reviewed human gold, and offline annotation causality
does not establish an online perception pipeline.

Each pipeline retains separate predictor-fitting, critic-fitting and held
source roles. Normalization and easy/hard cutoffs remain fitting-only. All
initial-state/preprocessing/ID/sampling comparisons match the cached control.
Held outcomes were not used to select hyperparameters, thresholds, seeds or
checkpoints in this fixed repair. Sources are nevertheless already exposed
development data, not independent final confirmation.

Inference accepts only the exact original causal packet. No future endpoint,
future-validity mask, future latent, oracle choice, central velocity, test
normalizer or test-endpoint goal enters inputs. Targets/masks are loss/eval
labels only. The loader can pack the original admitted source arrays, but
fitting diagnostics score only the original critic-fitting IDs. Reserved
calibration/confirmation sources and pending unused-source roles are not
opened by this experiment.

Available-label ADE for partial futures does not identify error at missing
steps. Wholly unknown rows retain conservative discrepancy H/EH contributions
and no observed reference mass; these are not fabricated true zero errors.
R/ER are not amplitude-scaled. Undefined support is never a measured safe zero.
No agent-type-specific effectiveness, metric calibration or effective-time
claim is established here. Native annotation steps are not verified raw video
frames or seconds; pixels are not metres or SDD raw t50.

## Training, Runtime And Recovery

Native arm64 `.venv-pytorch`, real Torch CPU4/interop1/workers0, no resource
probing. This experimental comparison is CPU-tested; MPS/CUDA performance is
not_run and is not inferred from the CPU path. Historical x86 Conda/Intel
MKL/OpenMP initialization is avoided by the entry guard before Torch import.

Source-balanced query72sampling, AdamW lr0.001, gradient clip5, original
physical fitting normalizers and original objective. Every fresh head receives
2,000 updates, at least 25 complete query visits: 36,000 primary updates.
The real three-fold exact-resume pilot and two full first-job refits are
additional verification, not primary work. All 18 raw initial states and
query streams match their controls. Both complete verification refits are
exact, including a fresh full control refit matching its original saved state.

Training: 1,627.621452 s, peak RSS 9,338,159,104 bytes. Complete held evaluation:
841.278129 s, peak RSS 5,691,883,520 bytes. Independent replay completion is
recorded separately: observed exit0asPID30996in180.764369s,peakRSS
5,530,927,104bytes. All36held cost outputs/policy scalars are exact, including
the original cached-control policies. Atomic checkpoints/heartbeat every100updates and explicit
same-binding resume are supported; no sample/budget downgrade was used.
Weights, raw data and intermediate caches remain private, not in Git.

## Evaluation And Reproduction

The complete matrix has 138 source/pipeline views and 348 repeated recording
views. Three thousand source-group resamples follow excluded-producer and
actual-seed averaging; these are nominal development intervals, not a
multiple-search correction. Independent selection/calibration/confirmation
are not_run for this repair. All original unsupported views remain.

Six controls: floor, uncontrolled neural, independent, query-uniform,
same-count joint and free joint allocation. Fixed 0.25s/query solver budget;
timeouts retain the predicted-feasible independent parent, not a risk
certificate or exact optimizer claim. The saved original-control allocations
are reused only after fresh cost/binding/feasibility/scalar checks. Separate
verification replays outputs/scalars and saved feasibility, not bitwise MIP
reoptimization. Empty same-count utility stays not estimable.

Use `operation_zh.md` and `protocol.md` for ordered commands, immutable stages,
resource boundaries and resume. Public code alone does not include third-party
data or private weights. Full legacy report-writing tests are not treated as
a readonly smoke test; focused checks and actual experiment receipts have
separate scopes. No stage5C execution or SMC. Formal paper submission still
requires the user's final confirmation and the unresolved scientific evidence.
