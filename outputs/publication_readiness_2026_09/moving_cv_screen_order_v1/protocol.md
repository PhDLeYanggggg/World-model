# Screen Before Nomination: Fitting-Source Intervention

Compare the order of screening and trajectory nomination using the same
frozen risk and pair heads, causal forecasts, blend fractions and cap (eight)
as the preceding admission study. Use its three disjoint fitting-source
rotations and three seeds. Analytic paths alone are used to select the
threshold on the calibration role; held rows use the verified source-excluded
neural donor forecasts as well. No new training and no A or DroneCrowd
confirmation readout.

At the previous fixed diagnostic setting (predicted tolerance .03, predicted
easy support .10), compare gain-only, nomination before screening, a shortlist
containing the original nominee plus full OLS4, full-bank screening, and
full-bank screening followed by pair-coupled recipient selection. The first
five arms match the number of edits in each query exactly. Coupling cannot
change the path nominated for an individual row. Separately run full-bank
screening up to the cap and the calibration-selected version. The latter
requires all calibration views to pass the original rule and positive
source-macro full-grid lower gain over both CV and OLS4, or returns CV.

Freeze all held choices before scoring. Primary diagnostic contrasts:
full bank and OLS4 addback versus nomination first, and coupled versus
independent full-bank screening. Report risk passes, unsupported views,
worst easy change and paired full-grid lower utility with 3,000 source
bootstrap draws after averaging seeds. Compare against CV and OLS4.
No support remains undefined. Fixed relaxed predicted tolerance does not
change the observed 2% criterion. This experiment is exploratory on
previously exposed fitting sources, not a new independent confirmation.
