# Where Do Wholly Missing Labels Limit The Native Forecast Bank?

Use the exposed Moving A development roster and the original native
eight-option forecast bank. Keep 34 recordings, 14 source groups,
three forecaster seeds, 8/12 native annotation steps, image pixels,
the exact same genuine query counts, CV fallback and OLS4 comparator.
Reproduce the 51 strict witnesses. This is a label-aware diagnostic,
not a revision to the external protocol or a selector.

Run a 2x2 ablation: retain or zero the wholly-unobserved-row disagreement
debit separately in (a) positive all/easy harm numerators and (b) the
conservative utility against each reference. Keep all eligible rows,
per-query weights, available-step ADE of partly observed trajectories,
observed denominators, the original signed easy rule and all selected
support requirements. Unobserved rows neither count as labeled nor
provide any reference mass. Setting a debit to zero is a diagnostic
convention, not a measured outcome, imputation, confidence bound, or
permission to relax deployment checks.

Use the same maximin objective and 3/12-second limits. Re-score each
positive witness using the relevant registered diagnostic and original
path/count checks. A positive witness under a stricter arm can carry
to a relaxed arm after re-scoring. Proven risk/count infeasibility can
carry to an arm that changes only utility, but never across the risk
relaxation. Do not carry negative objective bounds across relaxations.
Explicitly report unresolved cases. Main contrasts are the newly
positive views for each single debit omission and the combined omission.
Tabulate jointly opened views and each prior failure class. Report
paired source-bootstrap differences (3,000 draws, average seeds first).

These are tests of how the registered missing-label accounting affects
the finite candidate bank, not estimates of what annotations would
reveal. None of the diagnostic passes counts toward deployment.
No new training, external access, Stage5C or SMC.
