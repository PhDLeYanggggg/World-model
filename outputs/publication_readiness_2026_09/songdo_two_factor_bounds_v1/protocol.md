# Songdo two-order attribution

Use only the previously evaluated 160 confirmation flights and the
four recipient-by-path cells that were already frozen and scored.
The [Athens addendum](../pneuma_recipient_attribution_v1/protocol.md)
describes the shared-target bounds; here those rules are a retrospective
check. Preserve the original full-flight observed CV mass, the
existing query weights, all three seeds and 14 source components.
Verify the primary diagonal at every flight and seed and in all
source means. Average seeds within flight and flights within source;
reuse the original 3,000 source bootstrap draws. No calibration
data, new forecast fits, or new held-out targets enter this analysis.
