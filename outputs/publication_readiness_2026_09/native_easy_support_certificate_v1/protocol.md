# An Easy-Reference Feasibility Certificate

For the all-recipient diagnostic with up-to-count query limits, the
original risk rule is feasible if and only if one legal, distinct
easy action by itself has positive observed CV reference and harm
at most 2% of that reference. Sufficiency: use only that action;
all and easy ratios then coincide, and its signed easy harm is
bounded by the all-easy reference cap. Necessity: if all easy
actions exceed the limit, summing their strictly positive easy
excesses cannot be made nonpositive by non-easy actions or unknown
rows. A positive easy denominator requires at least one such action.

Check the criterion against all 102 prior fixed-budget solves, with
the same causal path bank, common translation and per-query caps.
Disclose how many distinct recordings explain the infeasible views
and report the minimum easy positive-harm ratio of each, with
aliases instead of original identifiers. This is a property of an
exposed, label-aware finite action space, not an inference procedure,
an OLS4 accuracy guarantee, or a criterion for intact multi-agent
groups with mandatory counts. Keep the original scoring unchanged.
