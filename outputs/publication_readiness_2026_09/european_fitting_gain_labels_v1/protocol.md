# Fitting-Only Signed Gain Labels

## Material Passport

This repairs a missing supervised-label field, not a model or a new primary.
The frozen easy-risk packets contain occurrence, reference cost and positive
harm, but omit benefit when the candidate beats its floor. That omission prevents
checking useful-switch ranking from those packets alone. No claim that utility
learning is new: the earlier joint-utility study already improved development
ADE while failing positive-harm risk control.

Before execution: cached_verified local forecasts, fitting roles and checkpoints;
new signed-gain sidecars not_run. The CREATE component diagnostic remains separate
and unchanged. It does not consume these new labels.

## Fixed Construction

Keep all108 groups, the existing three seeds, 4/4/2/2 source roles, original
floor/candidate forecasts, easy cut, per-group training scale and row order.
Use only each group's two fitting sources to calculate supervised costs. The
predictor/context receives only existing causal fields, with future fields removed.
Future trajectories enter the cost/label function only. No held readout or
independent selection/calibration/confirmation access, action generation, threshold
search or parameter update.

Export row ID, known mask, easy label, normalized reference/candidate costs,
signed_gain=(reference-candidate)/training_cost_scale, positive_benefit and
positive_harm. Benefit minus harm must equal signed_gain. A tie is zero; unknown
future labels stay NaN, never zero. Zero-CV rows retain the original non-easy
classification, not a new safety claim. The files are explicitly label-only.

Require IDs and original occurrence/reference/harm labels to reproduce the
frozen fitting identity exactly. Check the identity against the restored uncapped
checkpoint, which binds the original CREATE packet hashes. Preserve all existing
packets and registered component-diagnostic files.

## Execution and Verification

Run locally using native arm64 CPU4/interOp1/workers0; predictors and cost sources
already exist locally. First run one-group pilot to measure elapsed time, memory
and compressed bytes, then continue all108 with resume. Preserve10GiB free space;
estimate full storage from the pilot with a 3x allowance. If insufficient, retain
the pilot and report the resource blocker without narrowing groups.

Each completed group is immutable and hash-bound. Full replay recomputes the
labels and compares arrays and metadata, not ZIP timestamps. Record counts,
known/missing rows, beneficial/harmful/tied rows and row alignment. These are
repeated fitting views, not independent observations or efficacy estimates.
Only light aggregate reports and code go to GitHub; no row-level target cache.

Passing this construction enables later registered fitting-only utility checks.
It does not make old held results independent, validate a risk budget, authorize
deployment or prove a neural forecasting improvement. Observation8/prediction12,
raw stride12, image-local detector silver. No metric/seconds/human-gold/physical
safety/true3D/foundation/submission-ready claim. Stage5C/SMC remain disabled.
