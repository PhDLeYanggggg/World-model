# Learning Improves; Safe Admission Is Still Unproved

## What This Experiment Establishes

Adding the predeclared producer-A OOF donor treatment improves the matched
neural model on this already-exposed development screen. Source-macro decision
cost reductions are20.710862%,32.267086%,10.692731%; normalized risk-MSE reductions
are64.337175%,16.726303%,11.997147%. All eight source folds have lower decision
cost than their matched own-only model. The information screen passes3/3.

The preceding budget-only continuation did not repair transfer. The present
data treatment does. This supports improving the donor distribution rather
than blindly adding optimizer updates. It does not identify source count as
the sole causal factor: teacher fitting size and candidate mixture also change.
This is one risk-head seed and one OOF teacher seed, not independent confirmation.

The remaining problem is conditional harm and uncertainty near the admission
boundary, not merely average regression error. This is an inference from the
observed error decomposition, not proof that a particular uncertainty model
will fix it. No new threshold was chosen after seeing these slices.
