# OpenDD: learned angle choice with an explicit keep action

The finite oracle identifies useful angles without changing a single
recipient. Learn a conditional conservative gain for the same 12
nonzero angles and keep the original path when no estimated gain
is positive. The zero-angle score is exactly zero and wins ties.
There is no held-location threshold selection. This is a fixed
ranking rule, not a calibrated risk guarantee.

The direct arm fits observed and lower gains; the factor arm fits
observed gain and missing-step debit separately. Both see identical
held-excluded donor rows, bridge fractions, group-balanced draws,
architecture, initialization, 400 updates, and three seeds. Include
the best donor-average constant angle (or zero). To separate
admission from ranking, also force the factor head to use a nonzero
angle at exactly the direct head's rotation mask.

Keep the original 780 edited rows, 606 views, every per-step distance
from CV, and original 2% rule. Compare direct conservative utility,
dual passes, and the number of actual rotations. Use the existing
3,000 paired location draws after averaging seeds. No external
outcomes, deployment change, or use of label masks at inference.
