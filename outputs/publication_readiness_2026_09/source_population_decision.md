# Broader Source Population Diagnostic

This design precedes the new aggregate calculation. The previous native-motion
study does not justify another trajectory fit on its same stationary subset.
Here the full past-indexed population in the four already-explored source sites
is audited, including moving histories and incomplete labels. Bookstore, main,
outer, external and original validation/test readouts remain closed.

The question is whether moving/stopping/turning windows offer causal-baseline
headroom, and whether the frozen past-normalized ADE disproportionately weights
static-start events. Seven existing fixed causal rollouts are reused after hash
and schema checks. No new predictions, training, threshold tuning or deployment.
Other-site baseline selection is descriptive source crossfit, not confirmation.
The per-row future-informed oracle is diagnostic only.

Report supported masked ADE and complete-label results separately; unavailable
future labels remain unknown, never zero-motion negatives. FDE requires the
twelfth label. Preserve all indexed windows. Native annotation-pixel summaries
are diagnostics only and cannot replace the primary metric. Event categories
are retrospective labels, not inference features or independent human-gold
events. Count scoped tracks and disjoint spans without calling them independent.

If the audit reveals a consequential evaluation-scale issue, present the
evidence and request a scientific decision before changing the primary rule.
It is not permission to select a more favorable metric or discard static cases.
No Stage5C, SMC, seconds, metric, true-3D or foundation claims.
