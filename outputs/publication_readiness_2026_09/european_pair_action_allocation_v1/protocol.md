# Predicted-Path Interaction Control

Registered before this experiment's own policy scoring. Current evidence roles
and original two-percent all/easy positive-harm risk targets stay unchanged.
This is an exposed SOURCE fitting control,not independent validation.

## Hypothesis

The seven-action query allocator pools risk but does not optimize pairwise
predicted-path geometry. Does adding that term reduce interaction contraction
and improve robust ADE utility on the identical full target population?
The old binary implementation was tested on synthetic scores;that is not a
seven-action real-data result. Pairwise optimization itself is not a novelty claim.

## Frozen Comparison

Use all72 original source/context/critic-seed groups,the six contexts,all149510
unique target rows and74 recordings. Reuse the verified18 selected-set
query-unit critics with462 past-only features,all seven original forecasts and
the frozen unary full-joint choices. Seeds17/29/43 are critic seeds sharing
forecast-producer seed43,not three independently trained forecasters.

Compare the frozen unary full-joint policy to a pair-aware full-joint decoder.
Keep the exact original intervention count in every query,all action legality,
original reference predictions and both original2%predicted-risk constraints.
No fitted model,reference,risk threshold,role,or future mask changes.

Inference receives only the predicted moments,action availability,relative
candidate/floor paths,current origins,past scales and causal row/query IDs.
Restore all paths to common dataset-local coordinates. Form the undirected
union of each query target's four closest other current target origins;ties
use row ID. These are query targets,not all visible agents.

For each edge/action pair,the cost is the positive distance contraction
relative to the all-floor pair at the twelve requested timestamps,averaged
over steps and divided by the geometric mean of frozen past scales. This
matches the existing geometric readout's definition but uses the sparse
past-defined graph for inference. Also retain the old complete-pair readout.
It is not a body-aware collision or physical-safety metric.

Minimize negative total predicted net gain divided by total query past scale,
plus1.0 times the mean graph pair cost. The fixed1.0 coefficient is an
exploratory design constant,not selected from this readout. The MILP uses one
one-hot state per agent(including floor)and continuous pair transport variables
whose marginals equal the agent one-hot variables. Original budgets are not
normalized into a different target. No independent zero-weight solve is
claimed:the zero-weight arm is exactly the frozen verified unary control.

The original parent always remains feasible. A nonoptimal solver after two
seconds,nonfinite inputs or numerical risk/count/objective failure does not
authorize a new intervention. Retain the parent and count the fallback,never
drop the query or claim global optimality for the cohort. Zero-count/no-edge
and zero-parent-pair-cost queries retain the parent without a new optimality
claim. Continue to score all unknown-future rows and all required recordings.
