# Interpretation Rules Fixed Before Held Readout

This note does not change the registered contrasts, endpoints or gates.

1. If scaled true auxiliary improves its raw identity but not the equally
   scaled cost-only control, the result supports a generic magnitude adjustment,
   not a contribution from true auxiliary information.
2. If true and shuffled auxiliary improve similarly, do not attribute the
   gain to the cap-event task. Matched nuisance fitting remains essential.
3. If ranking remains useful but the registered expected-cost primary fails,
   two origin slopes are insufficient for cost transport. This does not prove
   the encoder contains no useful representation or that every calibration
   method must fail. Do not turn a failed mean-squared-cost result into a
   passed trajectory or policy result.
4. If source-held costs improve but tail/coverage/all-harm guards fail, do not
   advance a safety claim. Absence of a negative interval would still not be
   a formal noninferiority or physical-safety proof.
5. If fitting support is numerically adequate but event positives are absent
   or producer-specific easy cuts drift, report those facts. They are plausible
   transport limitations, not causal explanations established by this study.
6. If all registered screens pass, retain the result as source-development
   evidence only. The experiment estimates costs, not a new intervention
   policy; independent calibration and confirmation are separate later work.
7. Do not select a favorable producer/controller assignment, family, seed,
   slope cap or checkpoint after viewing these results. All registered
   assignments, including negative and unsupported comparisons, remain visible.

The main research goal still requires useful gain/harm estimates, matched
independent-agent versus scene-uniform versus scene-joint policies, easy/worst-
scene and interaction checks, independent calibration, final confirmation,
strong public baselines and a complete reproducible paper package. Finishing
this nested experiment alone cannot satisfy that goal.
