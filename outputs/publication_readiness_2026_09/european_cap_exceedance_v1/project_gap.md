# Project Gap After Cap-Event Probes

## What This Adds

The project now has a matched, three-seed native-Torch experiment showing
source-locality transfer of producer-relative cap-event information.
The simple linear model provides a strong control. Both its positive results
and the nonlinear model's incomplete gate are retained. This is a useful
risk-learning result, not an improved trajectory model or publication-ready
main claim by itself.

## Remaining Priority Gaps

1. **Expected cost and tail magnitude.** Event occurrence is not conditional
   severity. A matched joint-cost auxiliary experiment must improve the
   original estimator, not only weak probability/ranking controls.
2. **Scene-joint utility.** Compare independent-agent, whole-scene and joint
   intervention on identical forecasters and comparable intervention/risk
   budgets. Protect the zero-reference stratum and retain negative slices.
3. **Independent calibration and confirmation.** Source development has prior
   exposure. Four-locality exploratory intervals cannot replace untouched
   roles, effective support checks and a frozen final evaluation protocol.
4. **Method contribution.** Adding a classifier or combining JEPA/Transformer
   is not itself a novel, validated world-model contribution. Attribute any
   gain with matched retraining and appropriate simple controls.
5. **Paper completeness.** Main claims, matched public strong baselines,
   independent results, full reproducibility and submission materials still
   need completion. This project is not yet submission-ready.

## Next Narrow Test

Use cap-event supervision as an auxiliary label in a matched joint-cost
encoder, not a test-informed threshold and not an in-sample stacked score.
Keep the original forecasts, causal features, seeds and fixed budget. Retain
all assignments and localities. Register the exact objective, weight, teacher
lineage, cost/coverage gates and controls before fitting. A positive result
would justify the next controlled policy experiment; a negative result would
rule out that repair without opening independent confirmation.

## Boundaries

No new independent data access, policy deployment, Stage5C or SMC execution.
The main protocol remains obs8/pred12 native annotation steps in detector
pixels. Historical exposed scores remain exploratory; they are not restored
as clean tests by this new experiment. No metric, seconds-level, physical
safety, human-gold, true-3D or foundation-model claim is supported.

The long-term research goal remains active. Completion of this experiment
does not complete the world-model or submission-readiness goal.
