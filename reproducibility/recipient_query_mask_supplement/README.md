# Recompute the query selection contrast

Run `python3 -I -B -S verify.py` in the extracted directory. The review
archive contains seven anonymous location totals and paired means,
3,000 resamples and 126 anonymous direction budgets. It verifies the
movement constraint and reproduces the original mask from the inherited
comparison. No source trajectories, recording IDs or weights are needed.
It replays aggregate evaluation, not model training.
