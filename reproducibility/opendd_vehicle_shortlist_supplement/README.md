# Anonymous trajectory forecasting evidence replay

Run `python verify.py` in the extracted archive with Python 3.10 or later.
No model, raw trajectories, package install or network access is required.
The replay checks the archive manifest, reproduces the inherited panels and
reaggregates the eight shortlist arms, verifying equal intervention counts at
both matched budgets. It recomputes the paired 3,000-draw location bootstrap
from anonymised location means. The fixed-mask hindsight caps are supplied as
diagnostics, not scores achievable without the futures. This is aggregate
verification, not retraining or independent confirmation.
