# Anonymous reproducibility supplement

Run `python3 -I -B -S verify.py` in this directory. No training
weights, trajectories, or network access are required. This version
retains the previous panels and adds the fixed-recipient vehicle
comparison with restored observed spacing. It sums the grouped pass
counts and recomputes 95% intervals from 3,000 paired draws over seven
anonymous location means. These are repeated development views, not
independent confirmation or new releases.
