\section*{OpenDD development comparison}

We compare deterministic forecasts on the same 141,783 past-eligible
vehicle histories in 25,596 nonoverlapping queries and 500 recordings.
Each query uses eight observations and twelve forecast steps. For each
of seven held locations, all fitted models exclude that location and
use three fixed seeds. The deterministic adaptations use the same
completion loss, displacement cap relative to constant velocity (CV),
comoving frame, and 400-update budget. The social arms use the nearest
three observed vehicles; ego arms use only the focal history.

\section*{Reproduction}

The accompanying verify.py script recomputes estimates, risk counts,
and intervals from anonymous scalar receipts. It requires Python
3.10 or later and no datasets, checkpoints, or network. It verifies
aggregation rather than training. The prior evidence archive is included
unchanged.
