# Songdo recipient attribution: anonymous replay

Extract and run `python3 -I -B -S verify.py`. The new panel combines
the trajectory contrast for three disjoint recipient groups, then
resamples the same 14 linked sources. It checks that the total equals
the earlier frozen Songdo result. The input contains component means,
not trajectories, labels, flight names or checkpoints.

This is a retrospective attribution of the same fixed proposals.
It is not a new evaluation or an edited release rule.
