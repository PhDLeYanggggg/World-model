# WEPDTOF anchor and velocity attribution

Run `python3 -I -B -S verify.py` from the extracted folder. Python 3.10
or later is sufficient. The verifier averages anonymous clip summaries
within 13 sources and rebuilds 3,000 source bootstrap draws. It
reproduces retrospective contrasts on the previously evaluated
WEPDTOF clips; it does not open annotations, refit a forecast model
or reproduce a new independent test. The inherited replay is unchanged.
