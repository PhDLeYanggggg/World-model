# Selected-Pool Source Evidence: Standalone Numerical Reproduction

This package reproduces a **source-only aggregate diagnostic**, not model training,
raw-data extraction, a transfer result, an independent test or a deployment claim.
The complete diagnostic has 72 repeated head views from 12 previously exposed
development localities. Only 30 contrasts are defined, contributing eight localities.
The remaining 42 are retained as undefined rather than assigned zero risk.

## Run

Use Python 3.11 or later and NumPy. No PyTorch, GPU, dataset, checkpoint, repository
checkout, network access or CREATE credentials are required by `verify.py`.

```sh
python verify.py evidence.json
```

`evidence.json` is generated by the repository's source evidence exporter. Its
manifest records exact byte hashes; retain `manifest.json` with the package.
The exporter checks all 72 original source artifact hashes and the exact-replay
receipt before copying aggregates. It does not read transfer outputs. Locality
and view identifiers are replaced consistently, preserving dependence and order.
No author name, username, local path or repository URL is included in the exported
files. This is a technical de-identification check, not a guarantee of anonymity
against cross-referencing already-public numerical results.

## What Is Recomputed

For each frozen view the verifier checks retained-plus-removed moment partitions,
known/unknown counts, the observed and predicted easy positive-harm/reference
ratios, the exact retained/removed ratio identity and the signed bias contrast.
It reconstructs the figure's values from the aggregate moments, then repeats the
3,000-draw locality bootstrap with the original seed. Repeated heads are averaged
within locality, never treated as independent scenes. The numerical tolerance
for recomputed floating-point identities is 1e-9 relative and 1e-10 absolute;
artifact transport requires byte hashes, not these tolerances.

Moment order: benefit, positive harm, reference error, easy-reference error,
easy positive harm. Easy is an offline label defined by the training-fixed CV
error cutoff, not an inference feature. Reference error belongs to the protected
reference prediction and must not be silently replaced with CV error. Unknown
outcomes contribute neither zero labels nor known-outcome moment mass; their
counts and causal envelope are retained separately.

The risk budget remains 0.02. The primary bias is
`(EH - predicted_EH + 0.02 * (predicted_ER - ER)) / causal_envelope`.
The contrast is retained minus raw under the same adjusted predictions. Zero
denominators are undefined. This is not whole-easy ADE degradation or a calibrated
probability of a future collision.

## Expected Finding and Limits

Two heads in one locality become newly over-budget; both fail the existing source
screen. They are not two independent replications or an explanation of surviving
transfer failures. The defined-only mean bias change is approximately -0.012476,
with nominal interval [-0.072883, 0.035820]. The strict all-view mean is undefined.
The interval does not support universally increased optimism. Resampling opened
development localities does not provide independent confirmation or a 2% safety
guarantee.

This package cannot independently check raw trajectories, source split/teacher
lineage, causal feature construction, fitted calibrators or model inference.
Those require the separately recorded full source replay and data-access process.
Hashes establish file identity, not scientific validity. No future target is used
to construct an action here; the package contains only retrospective aggregates.

Protocol: observation 8 / prediction 12, stride 12 raw frames, image-local
detector-silver labels. No seconds, metric, human-gold, true-3D, foundation or
physical-safety claim. Independent roles remain closed; no policy change,
Stage5C execution or SMC is included.
