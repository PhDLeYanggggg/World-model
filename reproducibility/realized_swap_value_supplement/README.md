# Recompute the realized swap value contrasts

Run `python3 -I -B -S verify.py` in the extracted directory. The added
panel reproduces the fixed-count comparisons using anonymous location
means and paired draws. It verifies that the direct lower and upper
missing-label bounds bracket the observed contribution and that the
archived opportunity rule reproduces. This replay does not train models
and contains no raw positions, recording identifiers or weights.
