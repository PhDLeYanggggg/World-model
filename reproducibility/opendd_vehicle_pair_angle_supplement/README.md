# Anonymous forecasting evidence replay

Run `python3 -I -B -S verify.py` after extracting the archive to an empty
directory. The prior anonymous archive is retained byte for byte. This
panel checks matched intervention counts, aggregates replacement results
and replays 3,000 paired location draws. It needs no external package,
network, source labels or weights. This is an aggregate replay, not a
second training run or an independent evaluation.
