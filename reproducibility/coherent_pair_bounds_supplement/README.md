# Shared-position bounds: anonymous replay

Extract to an empty directory and run `python3 -I -B -S verify.py`.
The earlier evidence archive is preserved byte for byte. This audit
replays seven-location bootstrap intervals from anonymous site means
and verifies that the original bounds match the inherited panel.

`method.md` explains why a single missing position can be reused
across several edges. The witness counts are verified aggregate
properties of fixed development queries. The archive does not
contain the witness coordinates and cannot reconstruct them or
rerun inference.
