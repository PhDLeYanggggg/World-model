# Recompute the matched recipient eligibility comparison

Run `python3 -I -B -S verify.py` after extracting this archive. It uses
only the standard library. The new panel contains seven anonymous
location totals and paired means, and the bootstrap draws used for the
intervals. It verifies the exact equal-count comparison, opportunity
coverage and the original scope of the inherited evidence. The archive
contains no checkpoints, raw labels, coordinates or recording IDs.
It reproduces aggregated results, not model training.
