# Equal replacement count: anonymous replay

Run `python3 -I -B -S verify.py` after extracting this archive.
The new panel sums anonymous location-level counts and recomputes
the paired bootstrap estimates for the count-matched interval loss
ablation. The same-count random control is an expectation over each
model's own fixed proposals. The hindsight column is not a policy.

The previous archive is included unchanged. This replay contains
no track coordinates, checkpoints, participant identifiers or raw labels.
It verifies the reported aggregation, not training or forecast inference.
