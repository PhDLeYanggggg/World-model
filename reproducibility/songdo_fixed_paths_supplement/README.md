# Songdo: fixed-recipient path replay

Extract this archive and run `python3 -I -B -S verify.py`.
The new panel recomputes all paired source bootstrap intervals
for the four crossed comparisons and the original comparison.
It verifies that the observed contrast decomposes along either
path through the two-by-two comparison. The missing-label lower
bounds are direct comparisons and are not added.

The v23 archive is retained byte for byte. The added panel contains
only anonymous source means, not trajectories, labels or checkpoints.
