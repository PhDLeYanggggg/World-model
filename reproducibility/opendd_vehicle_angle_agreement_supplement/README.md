# Anonymous forecasting evidence replay

Run `python3 -I -B -S verify.py` in the extracted directory. Python 3.10
or later is sufficient; no external packages, weights or data are used.
The inherited archive replays the earlier panels. The new panel reaggregates
the two fixed-budget angle comparisons and recomputes paired location
intervals. The hindsight counts describe feasible alternatives, not fitted
policy performance. This checks aggregation, not model training.
