# Songdo: stricter displacement matching

Unpack the archive and run `python3 -I -B -S verify.py` with Python 3.10
or later. It recomputes the matched budget contrasts and intervals from
anonymous component means, using the original 14 source components and
3,000 source bootstrap draws. This is a sensitivity analysis on the
same scored flights, not another test or a new release decision.

The inherited review archive is unchanged. No private trajectories,
model weights or network access are needed for scalar replay.
