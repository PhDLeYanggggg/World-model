# External uncertainty replay

Extract this archive into an empty directory and run
`python3 -I -B -S verify.py`. The earlier anonymous evidence is
preserved byte for byte. The new panel uses anonymous Songdo component
means and fixed resampling indices to reconstruct the missing-label
upper bounds and separate source-bootstrap intervals. It also checks
the WEPDTOF bounds against the inherited replay. There are no raw
annotations or model weights.
