# Native-Stride Actor Aggregate Reproduction

This package replays the frozen primary results of three completed trajectory
actor experiments:prefix-balanced loss,past-image feature conditioning,and
query-view geometric conditioning. All three original component screens fail.
These are previously exposed development sources,not independent test evidence.

## Run

Use Python3.10or later from the extracted archive:

```text
python3 -I -S reproduce.py --verify --output reproduced
```

No network,model weights,raw trajectories,images,third-party packages or author
workspace are needed. The command checks file hashes,reconstructs fourteen-
source means,both producer folds,and the original3,000source-bootstrap draws.
The bootstrap index matrices are exported from each original registered seed;this
replays its arithmetic,not a new random bootstrap or independent confirmation.
Linear quantile interpolation is implemented with the standard library.
Archived numeric checks allow1e-12relative/1e-9absolute floating tolerance.
Expected generated tables and JSON files are also hash-checked.

All1/3/6/12prefixes and known/partial/wholly-unknown counts remain. Source IDs
are replaced by neutral aliases without changing their order or weights.
Observation8/prediction12uses native annotation stride1,image coordinates.
This is not the older stride12or raw-horizon task. No meters,verified seconds,
true3D,foundation or physical-safety claim is made.

## Boundary

Only aggregate numerical reporting is reproduced. Raw conversion,neural
training,prediction-bank replay,source-role integrity and full selected-policy
risk certification still require the separate original data/code/weights.
This is not a complete anonymous model-training release or submission package.
No risk threshold,support rule or undefined-value handling is changed. Old
negative results remain negative. No latent-generation execution or particle
proposal/resampling method is included.

The export removes direct author/local-path/repository markers with an allowlist
and fixed scan. That does not guarantee anonymity against recognition of
public numbers or methods. File hashes check accidental corruption,not an
attacker replacing the manifest and payload together. This draft has not been
submitted. Use a new output directory for a repeat run;existing outputs are
not overwritten.
