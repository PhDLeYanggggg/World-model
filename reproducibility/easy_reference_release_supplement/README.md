# OpenDD: predict whether the easy reference exists

Run `python3 -I -B -S verify.py` from this unpacked folder. Python 3.10+
is sufficient. The verifier checks the full seven-location roster, then
rebuilds release counts and paired conservative effects from 126 anonymous
direction receipts using 3,000 location resamples. The inherited replay
is unchanged. This archive does not train models, expose raw labels, or
turn the OpenDD development experiment into independent confirmation.
